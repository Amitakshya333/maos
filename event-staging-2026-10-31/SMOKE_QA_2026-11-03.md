Abandon the Cockpit round, log the exact error + exit code as a defect,
and switch to the CLI script (Task S steps 1–12) — the B2-evidenced
route. A failed Electron launch never blocks the CLI demo. Windows

mismatch, re-clone the event material with `-c core.autocrlf=false`
(the staging `.gitattributes` LF fix exists but was unpublished as of
