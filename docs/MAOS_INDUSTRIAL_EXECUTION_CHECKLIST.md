## A. Goal and agreed product boundaries

Deliver one reliable, reviewable MAOS Industrial journey: synthetic industrial input → analysis → evidence receipt → human review → report/artifact → independent verification. Keep MAOS Core compatibility, local/sovereign defaults, explicit approval, deterministic checks, provenance and truthful status. Use synthetic data only for hosted inference, and do not claim air-gapped behavior for hosted calls. MAOS Industrial is a project direction, not an incorporated company.

The seven-day delivery sequence is: (1) baseline and GUI inference reliability; (2) verify readiness/session behavior; (3) reproduce the local end-to-end journey; (4) verify stale-approval invalidation; (5) verify CLI and artifact parity; (6) integrate Meta-backed interpretation only after an approved spending/data envelope; (7) rehearse, freeze, and prepare submission assets.
