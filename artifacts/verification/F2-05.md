## Architecture

**Allowlist is the source of truth.** Only files matching a named allowlist rule are included. Denylist provides defense-in-depth: even if an allowlist rule accidentally matches, deny patterns block dangerous content.

```
File → Denylist check (FIRST) → Allowlist check → Include with rule attribution
```

|---|---|---|
