## Executive Summary

Task **UI1-03** has been completed and verified. The MAOS Industrial React SPA shell is now hosted and protected by the `ProjectServiceHost`, implementing a dedicated, ephemeral local session security architecture.

### Key Guarantees Enforced:
1. **Ephemeral Loopback Port Binding**:
   - `ProjectServiceHost` binds exclusively to `127.0.0.1` or `::1` on an ephemeral OS-assigned port (port 0 by default).
   - Any attempt to bind to `0.0.0.0`, LAN addresses, public IPs, or wildcard interfaces fails closed with `FORBIDDEN_BIND_HOST`.
   - Direct caller verification rejects remote IPs with `403 FORBIDDEN_NON_LOOPBACK`.

2. **Immutable Service Instance Identity**:
   - Generates a unique ephemeral `serviceInstanceId`, process PID, ephemeral port, project root path, project root SHA-256 hash, running executable path, and executable SHA-256 hash.
   - Durably records to `.maos/status/service-identity.json`.
   - **Identity File Hygiene**: Guaranteed zero tokens, secret keys, passwords, or credentials written to disk.
   - Automatically deletes the identity file on clean `stop()`.

3. **In-Memory Per-Window Session Tokens**:
   - Cryptographically random 64-hex session tokens (`crypto.randomBytes(32)`).
   - Stored exclusively in volatile memory via `SessionManager`. Never persisted to `localStorage`, `sessionStorage`, disk files, URLs, crash logs, or audit events.
   - Bound explicitly to `projectRootHash` and `serviceInstanceId`.
   - Verified using constant-time string comparisons (`crypto.timingSafeEqual`) to prevent side-channel timing attacks.

4. **Strict Origin & Non-Wildcard CORS Validation**:
   - Rejects `Origin: null` (sandboxed iframes / local files) with `403 FORBIDDEN_ORIGIN`.
   - Rejects `Origin: file://` with `403 FORBIDDEN_ORIGIN`.
   - Rejects external origins (`http://malicious.com`) with `403 FORBIDDEN_ORIGIN`.
   - Rejects missing `Origin` on browser state mutations (`POST`, `PUT`, `PATCH`, `DELETE`).
   - Loopback origins (`http://127.0.0.1:*`, `http://localhost:*`) echo exact origin; `Access-Control-Allow-Origin: *` is strictly forbidden.
   - CORS preflight `OPTIONS` requests respond with `204 No Content`.

5. **Token Hygiene & Rejection of URL Tokens**:
   - Tokens in URL query strings (`?token=...` or `?sessionToken=...`) are explicitly rejected with `400 FORBIDDEN_URL_TOKEN` on both REST and WebSocket endpoints to prevent leakage in server access logs, proxy logs, or browser histories.

6. **Secured Handshake & Revocation Endpoints**:
   - `POST /api/v1/auth/handshake`: Mints per-window session tokens with windowId and instance metadata.
   - `POST /api/v1/auth/revoke`: Revokes session tokens in memory; subsequent calls fail with `401 TOKEN_REVOKED`.
   - `GET /api/v1/auth/session`: Returns caller session metadata without leaking raw token or hash.
   - `GET /api/v1/service/identity`: Returns active instance identity.
   - Public bypass permitted only for `/api/v1/auth/handshake`, `/api/v1/openapi.json`, and `/api/v1/health`. All other routes require a valid Bearer token.

7. **Authenticated WebSocket Stream**:
   - Connects to `/api/v1/events` using subprotocol negotiation: `Sec-WebSocket-Protocol: ['maos-v1', 'maos-auth.' + token]`.
   - Server validates token and responds with `Sec-WebSocket-Protocol: maos-v1`, completely redacting the session token from the handshake response.
   - Unauthenticated, expired, revoked, or cross-project connections are rejected with `401` or `403`.

8. **Instance Renewal on Restart**:
   - Calling `host.restart()` revokes all existing sessions in memory and mints a fresh `serviceInstanceId`. All previous window tokens are rejected with `401` or `403 INSTANCE_MISMATCH`.
