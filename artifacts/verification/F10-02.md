# Phase F10-02 Verification: Replace One-Task Dashboard Trigger

## 1. Overview & Requirements
- **Goal:** Replace legacy one-task dashboard trigger (`POST /api/industrial/trigger`) with typed workflow call returning run and stage links.
- **Specification:**
  - Scope: Remove/migrate old trigger to typed workflow call.
  - Acceptance: Returns run/stage links (`/api/v1/runs/:runId`, `/api/v1/workflows/:stageId`, `/api/v1/cockpit/:runId`).
  - Negative Requirements: Direct fake `INGEST` assignment or duplicated engine path fails. All operations route strictly through `ServiceContainer` (`services.task`, `services.workflow`, `services.audit`).
- **Canary Hash Preservation:** `rust/test.txt` SHA-256 = `1392245502333919f23e58b8f544f12470db3829aabd5336a011e58d2b733435`.

## 2. Implementation Summary

### A. Dashboard Trigger Handler (`src/cli/dashboard.ts`)
1. **Removed Direct Core Queue Import:**
   - Deleted `import { createTask } from '../core/queue'`.
   - Imported typed `ServiceContainer` and `WorkflowStage`.
2. **Added `handleIndustrialTrigger`:**
   - Creates a typed objective task via `services.task.createTask({ type: 'objective', category: 'industrial-safety', capabilities: [...] })`.
   - Binds a typed workflow stage via `services.workflow.createObjective({ id: runId, goal, plannerAgentId: 'AUTO' })`.
   - Records an immutable audit event via `services.audit.recordAuditEvent({ category: 'stage', source: 'industrial-dashboard', data: { event: 'WORKFLOW_TRIGGERED', runId, stageId, goal } })`.
   - Returns typed `IndustrialTriggerResult`:
     ```typescript
     {
       success: true,
       runId,
       stageId,
       stage,
       task: { id, type, status, capabilities },
       links: {
         run: `/api/v1/runs/${runId}`,
         stage: `/api/v1/workflows/${stage.id}`,
         stages: `/api/v1/workflows/${stage.id}`,
         cockpit: `/api/v1/cockpit/${runId}`
       }
     }
     ```
3. **Mounted Route:**
   - `POST /api/industrial/trigger` invokes `handleIndustrialTrigger(services, cwd)` and returns JSON.

### B. Dashboard Template UI (`src/cli/dashboard-template.ts`)
- Updated `runSovereignAudit()`:
  - Button state transitions to `INITIATING WORKFLOW...` then `WORKFLOW ACTIVE...`.
  - Toast displays typed workflow run ID and stage ID with clickable links to `/api/v1/runs/:id` and `/api/v1/workflows/:id`.
  - Removed misleading `Task Dispatched [ID: INGEST_AGENT]` message.
