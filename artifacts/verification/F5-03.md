## Executive Summary

Implemented **F5-03: Local Knowledge-Base CPU Embedding Model Service**, establishing a pinned, offline sentence embedding model for local document chunks. The model configuration is strictly pinned to `sentence-transformers/all-MiniLM-L6-v2` (384 dimensions, `float32`, CPU execution, Apache-2.0, revision `fa979fdf926cbd99430f16e4321689952542a641`). Synthetic, hash-derived, random, or keyword vectors are strictly prohibited. The system enforces zero runtime downloads and fails closed if offline model snapshot assets are missing, malformed, or tampered. All vector embeddings preserve complete F5-02 chunk provenance (project ID, document ID, chunk ID, source hash, document version, character offsets, model ID, model revision, and dimension). The service integrates cleanly with `SharedModelManager` to lease the CPU embedding model without contending for GPU VRAM or evicting resident GPU vision-language models (e.g. Qwen2-VL).
