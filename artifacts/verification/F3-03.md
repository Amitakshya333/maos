## 1. Architectural Summary

F3-03 exposes the typed application services through a standardized HTTP OpenAPI REST contract under `/api/v1/*`. 

```
CLI Adapter ────────┐
Future React GUI ───┤──→ HTTP /api/v1/* (Loopback only) ──→ RestApiRouter ──→ ServiceContainer
Future Tauri Shell ─┘
```

### Architectural & Security Invariants Enforced

1. **Sole Business Logic Boundary**: The REST router contains **zero** business logic; every endpoint dispatches directly to typed methods on `createServiceContainer(projectRoot)`.
2. **Loopback-Only Interface**:
   - The HTTP server binds strictly to `127.0.0.1`.
   - Callers from non-loopback addresses are immediately rejected with `403 Forbidden` (`FORBIDDEN_NON_LOOPBACK`).
3. **Project-Root Scoping & Confinement**:
   - Headers and queries (`X-Project-Root`) are verified against the canonical project root. Mismatches or cross-project attempts are rejected with `400 Bad Request` (`PROJECT_SCOPE_MISMATCH`).
4. **Input Size & Body Limits**:
   - Request bodies are streamed with strict byte limits (max 1 MB). Payloads exceeding the limit are terminated with `413 Payload Too Large` (`PAYLOAD_TOO_LARGE`).
5. **Path Traversal Confinement**:
   - File access via artifact endpoints strictly asserts confinement within the project root. Traversal sequences (`../`, absolute paths outside root) are rejected with `400 Bad Request` (`PATH_TRAVERSAL`).
6. **Consistent Error Envelope**:
   - Every error response conforms to the standard envelope:
     ```json
     {
       "error": {
         "code": "VALIDATION_FAILED",
         "message": "Human readable message",
         "details": [],
         "correlationId": "corr_..."
       }
     }
     ```
7. **Request Correlation ID**:
   - Incoming `X-Correlation-ID` or `X-Request-ID` is preserved, or auto-generated if absent, and echoed in every response header and error envelope.
8. **Idempotency Key Handling**:
   - Mutating requests (`POST`, `PATCH`, `DELETE`) with `Idempotency-Key` headers are cached.
   - Identical replayed requests return cached responses with header `Idempotent-Replay: true`.
   - Conflicting requests with the same key but different payloads return `409 Conflict` (`IDEMPOTENCY_CONFLICT`).
9. **Zero Shelling**:
   - Neither the API server nor any client shells out to the CLI.
