## Executive Summary

Implemented **F5-05: Register `search_knowledge_base` Tool**, exposing deterministic, citation-preserving similarity search over the validated local vector index (`.maos/kb/vector-index.json`).

The tool is registered in `AGENT_TOOLS` with strict JSON Schema parameter validation (`schemaVersion: 1`, `projectId`, `query` <= 2048 chars / 100KB, `topK: 1..50` default 5, `minScore: 0.0..1.0` default 0.0, `filter`, `requestId`). Tool advertisement is gated via `getToolsForAgent` and authorized agents are confined to `AUTHORIZED_SEARCH_KB_AGENTS` (`research_agent`, `retrieval_agent`, `analyst_agent`, `compliance_agent`, `support_agent`).

Candidate ranking calculates deterministic cosine similarity across normalized 384-dimensional vector embeddings, sorting candidates primarily by `score` descending, with stable tie-breaking on `documentId` ascending, `chunkIndex` ascending, and `chunkId` ascending. Returned citations include complete provenance: `documentId`, `chunkId`, `sourcePath`, `pageNumber`, `sectionHeading`, `sourceHash`, `documentVersion`, `chunkIndex`, char offsets, `score`, `indexBuildId`, `embeddingModelId`, `embeddingModelRevision`, and hydrated `snippet` text safely retrieved from chunk storage. Zero citations, scores, or snippets are fabricated.

Explicit no-answer contracts per F5-01 are enforced: `'INDEX_NOT_BUILT'`, `'CORPUS_EMPTY'`, `'BELOW_CONFIDENCE_THRESHOLD'`, `'ALL_SOURCES_QUARANTINED'`, and `'QUERY_OUT_OF_SCOPE'`. Documents are treated as untrusted data only; snippets cannot alter policy, invoke tools, modify approvals, or bypass scope. Quarantined prompt-injected documents are strictly excluded from search candidates. Missing offline embedding weights fail closed immediately with `NO_RUNTIME_DOWNLOAD`. Replay and conflict prevention are guaranteed via durable idempotency tracking (`requestId`), and all search executions are recorded to the append-only audit trail (`KB_SEARCH_EXECUTED`, `KB_SEARCH_NO_ANSWER`) with cryptographic `queryHash` and zero raw query text or snippets logged.
