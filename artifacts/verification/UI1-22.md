## 3. Verified Accessibility & Recovery Dimensions

### 1. Actionable Recovery Across 6 Mandatory Domains
- **`reconnect`:** Loss of local loopback service/WebSocket triggers an assertive live alert with `CONNECTION INTERRUPTED` badge, retry countdown status, and an interactive "Reconnect Now" button.
- **`offline`:** Outbound network attempts violating the zero-cloud invariant trigger `OFFLINE BOUNDARY DEFENSE` with plain explanation ("Outbound HTTP call blocked by Industrial Firewall") and "View Allowed Endpoints" guidance.
- **`approval`:** Unapproved gates or unauthorized roles trigger `APPROVAL REQUIRED` with the required role ("Lead or Safety Engineer") and immediate "Review Approval Gate" / "Switch Role" actions.
- **`service`:** Local background process termination triggers `SERVICE FAULT` showing the stopped PID and a one-click "Restart Service" action.
- **`model`:** VRAM exhaustion or lease expiration triggers `MODEL RESOURCE EXHAUSTED` with options to "Switch to CPU Quantized" or "Unload Model".
- **`sandbox`:** Container script execution errors trigger `SANDBOX EXECUTION FAILED` with exit code details and "Inspect Run Trace" / "Edit Script" actions.

### 2. Negative Invariant Defenses
- **Zero Keyboard Traps:** Modals (`FilePickerModal`, `RoleOnboardingModal`) manage focus with `tabindex="-1"`, trap focus within dialog boundaries, and unconditionally dismiss on `Escape` key.
- **Zero Hidden Live Updates:** Dynamic error notices and status announcements are bound to `role="alert"` / `aria-live="assertive"` (or `role="status"` / `aria-live="polite"`).
- **Zero Color-Only Indicators:** Status badges and error categories always pair color with distinctive SVGs and uppercase textual labels (`CONNECTION INTERRUPTED`, `APPROVAL REQUIRED`, `SERVICE FAULT`, etc.).
- **Zero Raw Stack / Secret Leakage:** `sanitizeUserFacingError` strips raw V8/Node stack traces (`at Object.<anonymous> (...)`), removes internal filesystem paths, and redacts API keys (`sk-...`), Bearer tokens, and private keys to `[REDACTED]`.
- **Zero Indefinite Spinners:** `TimeoutSpinner` incorporates bounded timeout limits (`timeoutMs`), automatically halting rotation and rendering an actionable timeout alert with "Retry" and "Cancel" buttons if an asynchronous operation stalls.

### 3. Contrast & Reduced Motion Enforcement
- **WCAG AA Compliance:** Standard monochrome dark theme yields a contrast ratio of ~18.6:1 (text `#f0f0f0` on `#000000`) and >= 4.5:1 across surface levels.
- **WCAG AAA Compliance:** High-contrast theme (`[data-theme="high-contrast"]`) achieves 21:1 for white text and > 18:1 for yellow highlights (`#ffff00` on `#000000`).
- **Reduced Motion:** Both `[data-reduced-motion="true"] *` and `@media (prefers-reduced-motion: reduce)` clamp all CSS animation and transition durations to `0.001ms !important`, eliminating vestibular triggers.
