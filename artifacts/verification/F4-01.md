## Executive Summary

Task **F4-01** implements bounded, secure, offline PDF rasterization for industrial inspection, architectural drawing reviews, and scanned document analysis. The implementation converts PDF documents into high-fidelity raster images (PNG or JPEG) ready for downstream printed-text OCR (F4-02) and vision-language model analysis (F4-05).

Crucially, **F4-01** enforces strict fail-closed safety boundaries, defenses against malformed files and decompression bombs, project-root confinement, and integration into the single authoritative MAOS Artifact Store (`ArtifactService`) and cryptographic audit log (`AuditService`).

### Key Capabilities & Invariants

1. **Strict Resource and Content Bounds (`RASTER_BOUNDS`)**:
   - `maxSourceBytes`: 52,428,800 bytes (50 MB default). Rejects oversized source files (`BYTE_LIMIT_EXCEEDED`).
   - `maxPages`: 100 pages. Rejects documents exceeding authorized page bounds (`PAGE_LIMIT_EXCEEDED`).
   - `maxPageDimension`: 14,400 pt (200 inches @ 72 DPI). Rejects dimension bombs (`OVERSIZED_PAGE_DIMENSIONS`).
   - `maxRenderedPixelsPerPage`: 100,000,000 pixels (10,000 × 10,000). Rejects extreme DPI/pixel inflation (`PIXEL_LIMIT_EXCEEDED`).
   - `maxDecompressionRatio`: 100.0. Rejects nested FlateDecode zip-bombs (`DECOMPRESSION_BOMB_DETECTED`).
   - `maxDecompressedStreamBytes`: 104,857,600 bytes (100 MB). Prevents memory exhaustion from large decompressed streams.
   - `maxTotalOutputBytes`: 209,715,200 bytes (200 MB). Prevents disk-filling attacks across multi-page renderings (`OUTPUT_LIMIT_EXCEEDED`).
   - `timeoutMs`: 30,000 ms default. Kills hung rasterization processes (`TIMEOUT`).

2. **Strict Security & Fail-Closed Boundaries**:
   - **Path Traversal & Confinement**: Paths outside the project root are rejected with `TRAVERSAL_REJECTED`. Symbolic links escaping the project root are rejected with `SYMLINK_ESCAPE_REJECTED`.
   - **MIME & Magic Bytes**: Verifies `%PDF-` magic header bytes and `.pdf` extension. Rejects disguised non-PDF binaries with `INVALID_MIME` or `INVALID_EXTENSION`.
   - **Encrypted PDF Rejection**: Scans for `/Encrypt` dictionaries in the PDF header/trailer and fails immediately with `ENCRYPTED_PDF_UNSUPPORTED` rather than stalling.
   - **Decompression Bomb Defense**: Tracks input stream length vs. inflated byte count with sliding ratio checks during zlib/Flate decompression.

3. **Subprocess Isolation & Offline Engine**:
   - Pinned Python backend (`src/industrial/python/pdf_rasterizer.py`) running on local Python 3.14 + Pillow 12.3.0.
   - Invoked via Node `child_process.spawnSync` with `shell: false` to prevent shell injection.
   - Pure TypeScript fallback engine (`src/service/pdf-raster-service.ts`) capable of extracting standard Flate/DCT streams and encoding valid PNG images offline.
   - Zero remote assets, zero dynamic package downloads, zero telemetry.

4. **Safe Artifact Store & Audit Trail Integration**:
   - Rendered images are staged in `.maos/artifacts/.tmp/` scratch storage and finalized through `ArtifactService.finalizeArtifact()`.
   - Artifacts follow the safe 10-step lifecycle: `.tmp_*` -> `fsync` -> authoritative SHA-256 calculation -> atomic rename to `.maos/artifacts/<relPath>`.
   - SHA-256 hashes are calculated via the authoritative Rust engine bridge (`engineHash`), preserving the single cryptographic standard.
   - On rasterization success, an immutable audit event (`category: 'tool'`, `source: 'pdf-rasterizer'`, `action: 'PDF_RASTERIZED'`) is appended to `.maos/audit/audit-chain.jsonl`.
   - On error or validation failure, no partial artifacts are saved and **zero audit events** are emitted (guaranteeing zero phantom records).
