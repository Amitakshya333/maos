# Phase F10-05 Verification: Deterministic Reset

## 1. Overview & Requirements
- **Goal:** Add deterministic reset capability (`maos industrial reset`) for confirmed generated test state (queue, output, index, sandbox, conversation) with dry-run support and strict allowlist enforcement.
- **Specification:**
  - Scope: confirmed generated queue/output/index/sandbox/conversation test state by project/run.
  - Acceptance: dry-run and allowlist support (`--dry-run`, `--allowlist`, `--run-id`, `-y, --yes`).
  - Negative Requirements: Source fixtures (`fixtures/**`), demo source files, unrelated `.maos` files, recent projects, `rust/test.txt`, and audit trails cannot be removed.
- **Canary Hash Preservation:** `rust/test.txt` SHA-256 = `1392245502333919f23e58b8f544f12470db3829aabd5336a011e58d2b733435`.

## 2. Implementation Summary

### A. Deterministic Reset Engine (`src/industrial/deterministic-reset.ts`)
1. **Allowlist Categories Supported:**
   - `queue`: `.maos/queue/tasks/**`, `.maos/queue/objectives/**`, `.maos/plans/**`, `.maos/events/**`.
   - `output`: `artifacts/generated/**`, `.maos/generated/**`, `demo/industrial/generated/**`.
   - `index`: `.maos/industrial/kb/**` (vector indices and chunk manifests).
   - `sandbox`: `.maos/sandbox/**`, `.maos/tmp/**`, `.maos/artifacts/tmp/**`.
   - `conversation`: `.maos/sessions/**`, `.maos/conversations/**`.
2. **Strict Negative Invariants (`isForbiddenPath`):**
   - Canary check: Immediately rejects any path matching `rust/test.txt` or `rust/**`.
   - Fixture check: Immediately rejects `fixtures/**`.
   - Audit check: Immediately rejects `.maos/audit/**` (the cryptographic audit chain is immutable).
   - Verification check: Rejects `artifacts/verification/**`.
   - Core configuration check: Rejects `.maos/config.json`, `.maos/settings.json`, `.maos/instance-identity.json`, `.maos/keys.json`, `.maos/profiles/**`, `.maos/credentials/**`.
   - Demo source check: Rejects `demo/industrial/` source files (`turbine_vibration_log.csv`, `DEMO_PACK_PROVENANCE.json`, `safety_thresholds.json`, `expected_findings.json`, `maintenance_report.txt`, `turbine_inspection_scan.pdf`, `sop_turbine_vibration_monitoring.md`, `RUNBOOK.md`, `PRESENTATION_SCRIPT.md`, `images/**`), allowing only `demo/industrial/generated/**`.
   - Path traversal check: Validates that all candidate targets are normalized within `projectRoot`.
3. **Run ID Scoping:**
   - Filters tasks, objectives, plans, and events by `runId` when specified, ensuring isolation across parallel runs.
4. **Dry-Run & Confirmation Protocol:**
   - Defaults to `dryRun: true` when confirmation `--yes` is absent.
   - Live execution strictly mandates explicit confirmation (`--yes`), failing with `CONFIRMATION_REQUIRED` otherwise.
   - Records an immutable audit log (`DETERMINISTIC_RESET_EXECUTED`) upon confirmed execution.

### B. CLI Namespace Integration (`src/industrial/industrial-cli.ts` & `src/cli/index.ts`)
1. **Command:** `maos industrial reset`
   - Options: `-p, --project-root`, `--allowlist`, `--run-id`, `--dry-run`, `-y, --yes`, `--json`.
   - Stable numerical exit codes:
     - `SUCCESS: 0`
     - `INVALID_ARGS: 2`
     - `CONFIRMATION_REQUIRED: 4`
     - `RESET_FAILED: 8`
