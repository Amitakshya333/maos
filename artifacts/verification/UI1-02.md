## Executive Summary

Task **UI1-02** has been completed and verified. The MAOS React SPA shell now consumes the approved F3 OpenAPI 3.1 REST contracts and RFC 6455 sequenced event WebSocket streams through a robust, browser-safe typed client layer (`src/gui/src/api`).

The client adapter layer eliminates mock state across the GUI and enforces industrial guarantees:
1. **Strict Loopback Binding**: `BrowserRestClient` verifies the base URL and fails closed with `ForbiddenLoopbackError` on any non-loopback hostname or IP address (`127.0.0.1`, `localhost`, `[::1]`).
2. **Context Headers**: Outgoing requests automatically inject `X-Project-Root` and `X-Correlation-ID`. Mutating operations (`POST`, `PUT`, `PATCH`, `DELETE`) inject `Idempotency-Key` and detect `Idempotent-Replay: true` headers.
3. **Fail-Closed Runtime Validation**: Incoming payloads are validated against canonical domain schemas. Missing or incompatible `schemaVersion !== 1` throws `SchemaVersionError`, and malformed payloads throw `RuntimeValidationError`.
4. **Sequenced Event Client**: `BrowserEventClient` connects to the local `/api/v1/events` WebSocket stream, maintains in-memory monotonic cursor tracking (never in localStorage or web storage), detects and suppresses duplicate events, rejects conflicting sequence numbers, unpacks replay batches, and requests resync on sequence gaps or stale cursors.
5. **Clean Presentation-Only Views**: Read-only views and components (`TasksView`, `ModelsView`, `AuditView`, `ContextDrawer`, `Header`, `StatusBar`) are wired directly to `apiAdapter`. Zero Node built-ins (`fs`, `net`, `http`, `child_process`) or CLI shellings exist anywhere in `src/gui/**`.
