# Phase F10-07 Verification: Open-Artifact Integration

## 1. Overview & Requirements
- **Goal:** Safe, validated local deliverable opening for MAOS Industrial delegating to installed desktop office applications (Microsoft Office / LibreOffice / system viewer).
- **Specification:**
  - Scope: validated local DOCX/XLSX/PPTX using installed Office/LibreOffice.
  - Acceptance: explicit local open action (`maos industrial open <target>`).
  - Negative Requirements:
    1. Zero shell injection: Target path is sanitized; uses `child_process.spawn` with explicit argument arrays, never shell string concatenation.
    2. Zero remote URLs: Strictly prohibits remote or URL-based targets (`http://`, `https://`, `ftp://`, `file://`, UNC `\\server\share`).
    3. Zero directory traversal: Rejects traversal sequences (`..`) and paths outside project containment.
    4. Strictly allowed extensions: Only `.docx`, `.xlsx`, `.pptx`, `.pdf`. Rejects executables (`.exe`, `.bat`, `.cmd`, `.ps1`, `.sh`, `.vbs`, etc.).
    5. Zero implicit execution: Artifacts are opened only upon explicit user command invocation.
    6. No embedded editor claim: Explicitly documents delegation to installed desktop office software.
- **Canary Hash Preservation:** `rust/test.txt` SHA-256 = `1392245502333919f23e58b8f544f12470db3829aabd5336a011e58d2b733435`.

## 2. Implementation Summary

### A. Open-Artifact Service (`src/industrial/open-artifact.ts`)
1. **Target Safety Validation (`validateOpenTargetSafety`):**
   - Rejects empty, whitespace, and null targets.
   - Rejects protocol prefixes and remote URL patterns (`/^[a-zA-Z][a-zA-Z0-9+.-]*:\/\//i`, `file:`, `http:`, `https:`, `ftp:`, `smb:`).
   - Rejects UNC network shares (`\\\\` or `//`).
   - Rejects shell metacharacters and control sequences (`/[;&|`$><\r\n\0]/`).
   - Rejects directory traversal tokens (`..`).

2. **Resolution & Containment:**
   - Supports resolution by explicit Artifact ID (via `services.artifact.getArtifact`) or by relative project path.
   - Enforces containment within `projectRoot` (`path.relative(projectRoot, resolvedAbsPath)` cannot start with `..` or be absolute).
   - Enforces allowed extension set: `.docx`, `.xlsx`, `.pptx`, `.pdf`.

3. **Integrity & Anti-Tamper Verification:**
   - Verifies target file exists and is non-empty (0-byte files rejected with `INVALID_FILE`).
   - Computes authoritative SHA-256 hash of on-disk bytes.
   - When opened by explicit Artifact ID, verifies that the on-disk hash strictly matches the registered artifact hash, failing with `TAMPER_DETECTED` (exit code 1) on mismatch.

4. **Desktop Launcher Formulation (`formulateLaunchCommand`):**
   - Cross-platform launcher formulation using argument arrays (safe spawn):
     - **Windows (win32):**
       - Default (`auto`): `cmd.exe /c start "" <targetPath>`
       - Office (`office`): `winword <path>`, `excel <path>`, `powerpnt <path>`
       - LibreOffice (`libreoffice`): `soffice <path>`
     - **macOS (darwin):** `open <path>` or `open -a LibreOffice <path>` / `open -a "Microsoft Word" <path>`
     - **Linux:** `xdg-open <path>` or `libreoffice <path>`

5. **Mandatory Disclaimer Contract:**
   - Returns constant `NO_EMBEDDED_EDITOR_DISCLAIMER`:
     `"MAOS Industrial provides verifiable, deterministic deliverable generation and delegates viewing/editing to installed desktop office applications (Microsoft Office / LibreOffice). No embedded editor claim."`

6. **Audit Trail Logging:**
   - Emits `ARTIFACT_OPENED` audit event with relative path, SHA-256 digest, launcher, and dry-run flag, sealed into the tamper-evident audit log.

### B. CLI Integration (`src/industrial/industrial-cli.ts` & `src/cli/index.ts`)
1. **Command:** `maos industrial open <target>`
   - Options:
     - `-p, --project-root <path>`
     - `-l, --launcher <auto|office|libreoffice|system>` (default: `auto`)
     - `--dry-run`
     - `--json`
   - Exit Codes:
     - `SUCCESS: 0`
     - `FAILURE: 1` (e.g. tamper detected, empty file, launch spawn error)
     - `INVALID_ARGS: 2` (remote URL, shell injection, path traversal, unsupported extension)
     - `NOT_FOUND: 11` (file does not exist on disk)
