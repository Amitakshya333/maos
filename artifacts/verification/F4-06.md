## Executive Summary

Task **F4-06** implements a safety-critical conflict review engine that compares optical character recognition (OCR) facts against local Vision-Language Model (VLM) interpretations without silent merges, ungrounded heuristic character substitutions, or confidence inflation.

### Core Industrial Principles Enforced

1. **Independent Fact and Interpretation Records**:
   - OCR extracted text and VLM visual interpretations remain strictly separated and immutable.
   - Independent provenance is preserved: authoritative artifact ID, source hash, page number, pixel bounding box, engine/version (e.g. `tesseract-ocr:5.3.0`), model ID and revision (`Qwen/Qwen2-VL-2B-Instruct` / `aa70c964`), confidence scores, and timestamps.
   - Both sources are never merged into a single unqualified entity prior to comparison.

2. **Conservative Normalization (`normalizeObservationValue`)**:
   - Preserves `rawValue` unmodified.
   - Standardizes outer whitespace and internal multiple spaces.
   - Extracts unit without silent unit conversions (e.g., `10 bar` is never converted to `145 psi`).
   - Parses standard numeric floats for numerical equivalence checking (`24.50 mm` and `24.5 mm` evaluate as equivalent magnitude).
   - **Prohibits Heuristic Letter/Digit Substitution**: visual confusions such as `7O`, `1I`, `B8`, `S5` are detected and flagged as `AMBIGUOUS_SOURCE` rather than guessing `70` or `88`.

3. **Conflict Classification Matrix**:
   - `AGREE`: Identical normalized values, matching units, overlapping locations (IoU >= 0.05), and both confidences >= 0.60.
   - `OCR_ONLY`: Observation found only by OCR.
   - `VISION_ONLY`: Observation found only by VLM.
   - `CONFLICTING_VALUE`: Differing numeric or textual values between OCR and VLM.
   - `CONFLICTING_UNIT`: Differing units (e.g., bar vs psi or present vs absent).
   - `CONFLICTING_LOCATION`: Non-overlapping locations on the same page (IoU < 0.05).
   - `CONFIDENCE_DISAGREEMENT`: Low confidence (< 0.60) or delta >= 0.40 between sources.
   - `AMBIGUOUS_SOURCE`: Visually ambiguous character combinations detected.
   - `REQUIRES_HUMAN_REVIEW`: Safety-critical fields or unresolved discrepancies.

4. **Safety-Critical Gate**:
   - Automatically detects safety-critical keys (`vibration`, `pressure`, `temperature`, `clearance`, `voltage`, `current`, `speed`, `rpm`, `torque`, `bearing`, etc.) or explicit `isSafetyCritical: true`.
   - **Mandatory Review**: Even with 100% agreement and 1.0 confidence, safety-critical observations mandate human sign-off (`requiresReview: true`, report status `pending_review`).
   - "Higher confidence wins" automatic resolution is **strictly prohibited**.
   - Attempting `autoResolveItem` on safety-critical or conflicting items throws `ConflictReviewError('SAFETY_CRITICAL_AUTO_RESOLVE_BLOCKED')`.

5. **Five Explicit Human Review Decisions**:
   - `accept_ocr`: Accepts OCR observation; fails if no OCR observation exists.
   - `accept_vision`: Accepts Vision observation; fails if no Vision observation exists.
   - `enter_corrected_value`: Manual value and unit entry; fails if value is blank.
   - `mark_unresolved`: Sets status to `unresolved` with reviewer rationale.
   - `reject_both`: Rejects both observations as corrupted/erroneous.

6. **Safe Artifact Store & Immutable Audit Trail**:
   - Reports persisted to `evidence/conflicts/<sourceHash>/conflict-report-<id>.json`.
   - Resolved observations persisted to `evidence/resolved/<sourceHash>/resolved-<id>.json`.
   - Audit records emitted via `AuditService.recordAuditEvent` (`category: 'tool'`) strictly AFTER atomic artifact finalization:
     - `CONFLICT_REVIEW_CREATED`
     - `CONFLICT_RESOLVED`
   - Complete provenance retention in `ResolvedObservation` linking back to both original OCR and VLM sources.

7. **Project Containment & Document Hash Guardrails**:
   - Rejects observations belonging to a different project (`CROSS_PROJECT_FORBIDDEN`).
   - Rejects comparing observations originating from differing document source hashes (`SOURCE_HASH_MISMATCH`).
