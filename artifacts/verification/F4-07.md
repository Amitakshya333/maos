## Executive Summary

Task **F4-07** establishes the comprehensive, reproducible multimodal benchmark suite for MAOS, demonstrating operational stability, determinism, resource boundary compliance, and safety gating across the complete multimodal pipeline:

```text
input document/image
    ↓
bounded rasterization (PdfRasterService)
    ↓
printed-text OCR (OcrService)
    ↓
pinned VLM inference (VisionService via SharedModelManager lease)
    ↓
provenance comparison & conservative normalization
    ↓
conflict review & classification (ConflictReviewService)
    ↓
safe artifact finalization (ArtifactService)
    ↓
tamper-evident audit verification (AuditService via Rust engine)
```

The benchmark suite uses a frozen, licensed, non-proprietary manifest covering all 18 required fixture classes, executes 3 deterministic runs per supported fixture, asserts strict classification invariants, enforces the 6 GiB VRAM limit, and validates all 24 required negative security and failure scenarios.

## Determinism & Resource Budget Guarantees

1. **3-Run Repeatability**:
   - Every supported fixture was executed across 3 consecutive iterations.
   - Run-to-run invariants verified:
     - `inputSha256` remained byte-identical across all 3 runs.
     - `vlmModelRevision` remained pinned to `aa70c964147048705c93c4e16ff2bc55255470d0`.
     - `ocrEngineVersion` remained pinned to `5.3.0`.
     - `conflictClassification` remained identical across all 3 runs.
     - `requiresReview` remained identical across all 3 runs.
     - `isSafetyCritical` remained identical across all 3 runs.
     - Zero determinism errors reported (`determinismErrors.length === 0`).

2. **VRAM & Latency Budgets**:
   - Peak VRAM measured across all iterations: **3072 MiB**, strictly within the **6144 MiB (6.0 GiB)** budget limit.
   - Cold-start latency strictly within manifest budget ($\le 45,000\text{ ms}$ GPU / $\le 180,000\text{ ms}$ CPU).
   - Inference latency strictly within manifest budget ($\le 15,000\text{ ms}$ GPU / $\le 60,000\text{ ms}$ CPU).

3. **Safety-Critical Gate & Independent Provenance**:
   - Measurements involving safety-critical parameters (`clearance`, `pressure`, `temperature`, `vibration`) mandate human review (`requiresReview: true`), even when OCR and VLM 100% agree.
   - Auto-resolution for safety-critical fields is strictly blocked (`ConflictReviewError: SAFETY_CRITICAL_AUTO_RESOLVE_BLOCKED`).
   - OCR facts and VLM observations are never merged into unqualified claims prior to human review.

4. **Safe Artifact Store & Immutable Audit Trail**:
   - Benchmark reports atomically finalized at `evidence/benchmarks/multimodal-benchmark-<id>.json`.
   - Audit event `MULTIMODAL_BENCHMARK_COMPLETED` recorded strictly after artifact finalization.
   - Complete audit trail verified using the Rust industrial engine (`verifyChain().valid === true`).
