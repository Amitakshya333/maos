## Executive Summary

Task **F4-03** exposes bounded optical character recognition to authorized industrial agents through the standard MAOS tool boundary (`ocr_document`).

### Core Industrial Principles Enforced

1. **Strict Defense-in-Depth Authorization & Role Isolation**:
   - Direct subprocess execution, Python invocation, Tesseract, and host shell execution are completely prohibited for agents.
   - The tool is advertised only to authorized agent roles (`INGEST_AGENT`, `ANALYST_AGENT`, `AUDITOR_AGENT`, `inspector`, etc.) via `getToolsForAgent`. Unauthorized agents never see the tool definition.
   - At execution time, caller identity and `allowedTools` are strictly validated before any filesystem or subprocess action. Unprivileged agents receive `TOOL_UNAUTHORIZED` or `UNAUTHORIZED_TOOL_CALL`.

2. **Versioned Input Validation & Bound Enforcement (`OcrDocumentInput`)**:
   - Enforces `schemaVersion: 1`, non-empty `projectId`, `requestId`, and canonical project-confined `sourcePath`.
   - Strictly rejects directory traversal (`..`), null bytes, backslash escapes, and paths resolving outside the project root.
   - Enforces `.pdf` extension and checks `%PDF-` magic byte header before dispatch.
   - Enforces source file size limit (`OCR_BOUNDS.maxSourceBytes = 50 MB`).
   - Validates 1-indexed bounded page ranges (`start >= 1`, `end >= start`, `end - start + 1 <= maxPages`).
   - Validates allowlisted language tags (`'en'`, `'eng'`). Rejects unsupported languages with typed `UNSUPPORTED_LANGUAGE`.

3. **Durable Mutation Idempotency**:
   - Integrated with `DurableIdempotencyStore` using `requestId`.
   - Exact replayed requests return cached results (`cached: true`) without re-running rasterization, OCR, or emitting duplicate audit events.
   - Replays with conflicting payloads trigger `IDEMPOTENCY_CONFLICT`.
   - Replays with mismatched authorization contexts fail closed with `UNAUTHORIZED_TOOL_CALL`.

4. **Complete Provenance & Immutable Audit Trail**:
   - Emits a tool-level audit event (`category: 'tool'`, `source: 'ocr_document'`, `action: 'DOCUMENT_OCRED'`) strictly on successful execution.
   - Returns typed `OcrDocumentToolResult` preserving `sourceArtifactId`, `sourceHash`, total page count, aggregate confidence, and per-page results with `artifactId`, `artifactHash`, bounding boxes, and confidence.
   - Zero phantom audit events or orphaned temporary files on validation or execution failure.

5. **Reuse of Core Infrastructure & Zero Duplication**:
   - Reuses F4-01's `PdfRasterService` (synchronous and asynchronous pipelines).
   - Reuses F4-02's `OcrService`.
   - Reuses `ArtifactService` for Safe Artifact Store atomic finalization.
   - Reuses `AuditService` for append-only tamper-evident audit records.
   - Reuses `DurableIdempotencyStore` for crash-safe idempotency guarantees.

## Technical Specifications

### 1. Versioned Input Schema (`OcrDocumentInput`)

```typescript
export interface OcrDocumentInput {
  schemaVersion: 1;
  projectId: string;
  sourcePath: string;
  sourceArtifactId?: string;
  language?: string;
  pageRange?: {
    start: number;
    end: number;
  };
  confidenceMode?: 'standard' | 'strict';
  requestId: string;
  expectedSourceHash?: string;
}
```

### 2. Versioned Output Schema (`OcrDocumentToolResult`)

```typescript
export interface OcrPageToolResult {
  pageNumber: number;
  artifactId: string;
  artifactHash: string;
  confidence: number;
  warnings: string[];
  blockCount: number;
}

export interface OcrDocumentToolResult {
  schemaVersion: 1;
  sourceArtifactId: string;
  sourceHash: string;
  totalPages: number;
  text: string;
  averageConfidence: number;
  warnings: string[];
  pageResults: OcrPageToolResult[];
  engine: string;
  engineVersion: string;
  auditEventId: string;
  cached?: boolean;
}
```

### 3. Tool Registration & Execution Pipeline

```text
Agent tool request
    ↓
Tool registry filter (getToolsForAgent / allowedTools check)
    ↓
Typed validateOcrDocumentInput(input)
    ↓
Project-root & scope confinement check (projectFile / isPathInScope)
    ↓
MIME (%PDF-) & byte limits check
    ↓
DurableIdempotencyStore.claim()
    ↓ (if replay: return cached result)
PdfRasterService.rasterizeSync()
    ↓
OcrService.ocrImageSync() for each rendered page
    ↓
Safe Artifact Store finalization (evidence/ocr/...)
    ↓
AuditService.recordAuditEvent(DOCUMENT_OCRED)
    ↓
DurableIdempotencyStore.complete()
    ↓
Typed OcrDocumentToolResult returned to agent
```
