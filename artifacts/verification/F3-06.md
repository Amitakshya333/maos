## 1. Architectural Summary

Phase **F3-06** implements an append-only, tamper-evident audit event log backed by the release Rust industrial engine (`maos-industrial-engine`), with deep recursive sensitive-data redaction.

### Invariants Enforced

1. **Zero Plaintext Secrets on Disk Invariant**:
   - Every audit record passes through `redactSensitive()` prior to canonical hashing or disk persistence.
   - Sensitive credentials (OpenAI/Anthropic keys, JWTs, Bearer tokens, PEM private keys, passwords) are replaced with `[REDACTED]` markers.
   - Raw disk audit files (`.maos/audit/audit-chain.jsonl`) never contain plaintext secrets.

2. **10 Mandatory Audit Categories**:
   - `stage`: Lifecycle transitions (start, complete, fail).
   - `tool`: Agent tool invocations, inputs, and durations.
   - `model`: Model routing decisions, token counts, and parameters.
   - `endpoint`: Local/loopback HTTP calls and latency metrics.
   - `lease`: GPU model manager lease acquisitions and releases.
   - `io_hash`: Cryptographic SHA-256 inputs/outputs verification.
   - `duration`: Execution timing metrics for workflows and stages.
   - `warning`: Threshold exceedance and non-fatal system warnings.
   - `approval`: Governance gate decisions, approvers, and conditions.
   - `interruption`: User cancellations, aborts, and timeout events.

3. **Authoritative Rust Engine Hash Chain**:
   - Each record is cryptographically linked using canonical JSON SHA-256 (`sequence|previous_hash|timestamp|source|category|canonical_data`).
   - The verified release binary `rust/target/release/maos-engine.exe` calculates hashes via `chain-append` and verifies chains via `chain-verify`.
   - Any modification, deletion, reordering, or gap is detected and fails closed.

4. **REST API & Idempotency**:
   - `GET /api/v1/audit`: Filterable by category, source, sequence bounds, and limit.
   - `POST /api/v1/audit/events`: Ingestion with auto-redaction and optional idempotency keys.
   - `POST /api/v1/audit/verify`: Complete chain integrity check via Rust engine.
   - Documented in OpenAPI 3.1.0 specification.
