## VRAM Budget (8 GB RTX 4060)

With the shared GPU Model Manager (serialized by default, one model loaded at a time):

| Scenario | VRAM Usage | Feasible |
|---|---|---|
| Text model only | ~6 GB | ✅ |
| Coder model only | ~6 GB | ✅ |
| Vision model only | ~7 GB | ✅ (tight) |
| Text + Coder concurrent | ~12 GB | ❌ Exceeds 8 GB |
| Any model + Embedding | Model VRAM + ~0 (CPU) | ✅ |

**Conclusion:** serialized model loading with 3-minute idle unload is mandatory. No concurrent GPU model loading.
