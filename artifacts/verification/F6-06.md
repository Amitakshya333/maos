## Executive Summary

Task **F6-06** implements an air-gapped, zero-dependency visual-review subsystem that validates the rendered appearance, layout bounds, readability, typography, non-overlapping canvas placement, and structural quality of generated `DOCX`, `XLSX`, and `PPTX` deliverables without requiring external office runtimes (e.g. LibreOffice or Microsoft Office).

The subsystem inspects generated office packages in-memory, extracting geometric dimensions, table grid measurements, slide shape coordinates, safety elements, and formatting attributes to guarantee:
1. Deliverables are openable and conform to OOXML packaging standards.
2. Content is legible, properly padded, and free of clipped or overlapping shapes.
3. Strict visual governance and safety boundaries are present:
   - Prominent verdict banner (`PASS`, `FAIL`, `CONDITIONAL`).
   - Reviewer sign-off block with role, timestamp, and signature status.
   - 5-column cryptographic citation ledger.
   - Mandatory engineering units on all measurements.
   - Clearly segregated generative prose highlighted with an amber warning banner (`#FFFBEB` background, `#B45309` text, `UNVERIFIED MODEL PROSE` disclaimer).
4. Layout snapshots produce deterministic SHA-256 hashes across repeated generations.
5. All reviews emit privacy-preserving audit events (`VISUAL_REVIEW_PASSED`, `VISUAL_REVIEW_FAILED`) without raw prose or token leakage.

## Architecture & Implementation Details

### 1. Zero-Dependency OOXML Visual Layout Inspector (`src/industrial/office/visual-review.ts`)

- **Format-Specific Visual Parsers**:
  - `inspectDocxVisuals(buffer, options)`:
    - Parses `word/document.xml` and `word/styles.xml`.
    - Computes page dimensions and printable width in twips (`pageWidth - marginLeft - marginRight`, standard 9,360 twips on Letter).
    - Validates table widths against printable width; detects clipped tables (`TABLE_OVERFLOW`).
    - Validates table column grid allocations (`TABLE_GRID_MISMATCH`).
    - Checks font sizes (verifies body font >= 9pt, flags `TEXT_CLIPPED_RISK`).
    - Verifies presence and formatting of required visual governance elements:
      - Prominent verdict banner (`MISSING_VERDICT_BANNER`).
      - Formal reviewer sign-off block (`MISSING_SIGN_OFF`).
      - Segregated unverified model prose (`PROSE_NOT_SEGREGATED` if prose lacks amber shading `#FFFBEB` or `UNVERIFIED MODEL PROSE` heading).
      - Citation ledger verification with cryptographic source hashes.
      - Engineering units on measurements.
  - `inspectXlsxVisuals(buffer, options)`:
    - Parses `xl/workbook.xml`, `xl/styles.xml`, and `xl/worksheets/sheet*.xml`.
    - Validates worksheet sheet counts and names.
    - Inspects column widths against text lengths; flags narrow columns risking number overflow (`CELL_OVERFLOW_RISK`).
    - Verifies header styling (`font-weight: bold`, background fills).
    - Checks required sheet structure: Summary tab, Citations tab, Findings tab.
    - Verifies presence of verdict and reviewer sign-off metadata rows.
    - Flags unsegregated model prose lacking explicit amber background shading or disclaimer markers.
  - `inspectPptxVisuals(buffer, options)`:
    - Parses `ppt/presentation.xml` and `ppt/slides/slide*.xml`.
    - Enforces 16:9 widescreen canvas standard (`12,192,000 × 6,858,000` EMUs).
    - Computes shape bounding boxes (`x`, `y`, `cx`, `cy`) for titles, content boxes, banners, and tables.
    - Detects canvas overflow (`OUT_OF_BOUNDS` when shape extends past canvas width/height).
    - Detects shape collision and overlapping content (`SHAPE_OVERLAP` when bounding boxes intersect by more than 5%).
    - Verifies title slide presence and minimum font size legibility (titles >= 20pt, body >= 12pt).
    - Verifies verdict banner, reviewer sign-off, and segregated prose styling on summary/conclusion slides.

- **Deterministic Layout Snapshot Hashing**:
  - Extracts canonical layout metrics (page/slide count, element counts, table column grids, bounding boxes, text lengths, safety block flags).
  - Normalizes numbers and sorts keys deterministically before computing SHA-256 hash (`visualSnapshotHash`).
  - Guarantees identical layout hashes across repeated deliverable builds from identical input.

### 2. Centralized Review Service (`src/service/office-visual-review-service.ts`)

- **Service Interface**:
  - `reviewDeliverable(buffer, artifactType, relativePath, options)`: Inspects buffer synchronously and generates an `OfficeVisualReviewReport`.
  - `reviewDeliverableAsync(buffer, artifactType, relativePath, options)`: Async wrapper supporting file path reads and stream evaluation.
  - `assertVisualAcceptance(buffer, artifactType, relativePath, options)`: Strict quality gate throwing typed `VisualReviewError` if any `error`-level issue is detected.
  - `assertDeterminism(bufferA, bufferB, artifactType, relativePath)`: Verifies visual snapshot hashes match across builds.
- **Privacy-Safe Audit Integration**:
  - Emits `VISUAL_REVIEW_PASSED` on success and `VISUAL_REVIEW_FAILED` on failure.
  - Logs artifact path, artifact type, snapshot hash, and error codes.
  - Excludes raw model prose, text content, and sensitive values from audit entries.
