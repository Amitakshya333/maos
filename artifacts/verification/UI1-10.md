## Executive Summary

Task **UI1-10** delivers formal operational safety contracts and scoped data retention policies to the MAOS interactive interface, directly realizing the industrial safety invariants required for regulated engineering workflows:

1. **Dual Operational Modes: Evidence vs Brainstorm**:
   - **Evidence (Industrial) Mode (Default)**:
     - Every factual claim asserted by a model or operator MUST include cryptographic citations (`ClaimCitation`) with valid 64-character hex SHA-256 source hash, non-empty source path, and exact evidence snippet.
     - Uncited claims in Evidence mode are strictly rejected with typed error code `UNCITED_CLAIM_REJECTED`.
     - Model-generated prose pending human verification is prominently badged with `UNVERIFIED_MODEL_PROSE` visual warnings.
   - **Brainstorm Mode**:
     - Permits rapid, ungrounded exploratory generation without mandatory citations (`isModelGenerated: true`, `verifiedAgainstData: false`).
     - A claim without citations cannot falsely claim to be verified against data (`BRAINSTORM_UNVERIFIED_ASSERTION`).
     - Unreviewed brainstorm explorations are strictly forbidden from being promoted to executable tasks or finalized deliverables without explicit operator review and confirmation (`BRAINSTORM_UNVERIFIED_CLAIM_REQUIRES_REVIEW`, `allowUnreviewedBrainstorm: true`).
   - **Silent Downgrade Defense**:
     - Switching an existing session from Evidence mode down to Brainstorm mode without explicit confirmation is rejected (`SILENT_DOWNGRADE_FORBIDDEN`). Upgrading from Brainstorm to Evidence is always permitted.

2. **Configurable Local Retention & Scoped Purge**:
   - Retention parameters are validated and bounded to [1, 365] days aligned with `BasicSettings.retention`:
     - `conversationDays`: Retention window for unpinned conversations (default: 30 days).
     - `eventDisplayDays`: Retention window for local UI event display buffers (default: 7 days).
     - `artifactPreviewDays`: Retention window for temporary preview cache files (default: 14 days).
   - **Strict Path Containment**: All purge targets are verified to reside inside `projectRoot`. Any path traversal (`../`, null bytes, absolute escape paths) is rejected (`PATH_OUTSIDE_PROJECT`).
   - **Immutable Safety Invariants**:
     - Append-only audit records (`.maos/audit/`) are **strictly immutable** and NEVER purged under any circumstances (`IMMUTABLE_AUDIT_PURGE_FORBIDDEN`).
     - Finalized office deliverables (`artifacts/*.docx`, `*.xlsx`, `*.pptx`) are NEVER purged (`FINALIZED_DELIVERABLE_PURGE_FORBIDDEN`).
     - Pinned conversations (`pinned: true`) and task-linked conversations (`taskId` present) are immune to retention purges.
     - Only expired unpinned conversations and temporary preview caches (`artifacts/.tmp/*`, `.maos/previews/*`) are reclaimed.
   - **Dry-Run Preview & Tamper-Evident Auditing**:
     - Operators can preview purge operations before execution (`dryRun: true`), observing candidate file counts and estimated byte reclamation.
     - Executed purges record structured, privacy-preserving audit events (`RETENTION_PURGE_COMPLETED`) without exposing sensitive payload text.

3. **User Interface Implementation**:
   - **ChatView**:
     - Mode badge and dropdown selector in conversation header (`Evidence Mode (Verified)` vs `Brainstorm Mode (Exploratory)`).
     - Downgrade confirmation modal dialog with warning and operator acknowledgment.
     - Pinned toggle button with visual pin icon indicating retention protection.
     - Warning banner on unverified model prose: `⚠️ Unverified Model Prose — Citation Required in Industrial Mode`.
     - Expandable citation chips rendering source file, SHA-256 fingerprint, page/section reference, and evidence snippet.
     - Task promotion modal with brainstorm acknowledgment checkbox when unreviewed claims exist.
   - **SettingsView**:
     - Scoped Local Purge management card under Section 1 (Retention & Redaction).
     - Real-time retention metrics: total & expired conversations, preview caches, reclaimable bytes, and immutable audit/deliverable counts.
     - "Preview Purge (Dry Run)" and "Execute Scoped Purge" buttons with modal confirmation.

4. **4-Way Parity Across API Layers**:
   - Full interface parity across `ServiceContainer` (`evidenceMode`, `retention`), `RestApiRouter`, `BrowserRestClient`, and `GuiApiAdapter`.
