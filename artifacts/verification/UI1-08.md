## Executive Summary

Task **UI1-08** is the final task of the UI1-A foundation track. It implements safe user/project preferences without allowing settings to weaken industrial security or runtime policy:

1. **Retention and Redaction Settings**:
   - `conversationDays`: Retention period for conversation history (clamped [1, 3650] days, default 30).
   - `eventDisplayDays`: Retention period for event/audit display in GUI (clamped [1, 3650] days, default 90).
   - `artifactPreviewDays`: Retention period for artifact preview caches (clamped [1, 3650] days, default 14).
   - `redactSensitivePreviews`: Boolean toggle ensuring sensitive tokens/hashes/keys are masked in UI previews (default `true`).
   - `allowRawEvidencePreviews`: Security toggle controlling whether raw un-redacted evidence is previewable in the UI (default `false`).
   - **Boundary Enforcement**: User settings control display/caching only. Mandatory append-only audit persistence and cryptographic hash chain verification cannot be disabled or bypassed by any settings preference.

2. **Idle Model Behavior and Service Stop Control**:
   - `modelUnloadAfterSeconds`: Idle grace period before unallocated GPU model memory is freed (clamped [30, 86400] seconds, default 300 = 5 minutes).
   - `serviceStopAfterSeconds`: Idle duration before local background host shuts down (clamped [60, 86400] seconds, default 1800 = 30 minutes).
   - `stopBehavior`: Default shutdown preference (`'after-current-tasks' | 'force'`, default `'after-current-tasks'`).
   - **Graceful Stop vs Force Stop**:
     - `after-current-tasks`: Checks active queue/running tasks. If active work exists, returns `activeTasksCount` without aborting inflight work.
     - `force`: **Strictly requires explicit confirmation parameter** (`confirmForce: true`). Unconfirmed force-stop requests are rejected with `CONFIRMATION_REQUIRED` (HTTP 400).
   - **Force-Stop Execution Guarantee**:
     - Active tasks are transitioned to status `'interrupted'`, eliminating phantom success.
     - Unfinalized partial artifact files (`.tmp_*`) are cleaned up from `.maos/artifacts/`.
     - An immutable audit event (`category: 'interruption'`, `action: 'SERVICE_FORCE_STOPPED'`) is written to the audit log with actor and reason.
     - All GPU model leases are freed via `ModelService.releaseAllLeases()`.
     - Process exit is scheduled cleanly without corrupting state.

3. **Accessibility and Display Settings**:
   - `theme`: `'dark' | 'high-contrast'` (default `'dark'`).
   - `reducedMotion`: Boolean flag respecting system or user vestibular preferences (default `false`).
   - `fontScale`: Text scaling multiplier clamped [0.8, 2.0] (default 1.0).
   - `density`: Visual density spacing (`'compact' | 'comfortable'`, default `'comfortable'`).
   - Applied dynamically to DOM via `ThemeContext.tsx` attributes: `data-theme`, `data-reduced-motion`, `data-density`, and `--font-scale` CSS custom property.

4. **Local Endpoint and Sovereignty Visibility**:
   - GUI displays local loopback endpoint (`http://127.0.0.1:<port>`), redacted service instance ID (`inst-***-1234`), active project root, Rust engine verification status, and resident model VRAM metrics.
   - Zero credentials, API keys, session tokens, or private environment variables are stored in settings or exposed via the visibility API.

5. **Atomic Persistence & Resilient Recovery**:
   - Settings stored at `.maos/settings/basic-settings.json` using unique temporary file writes followed by `fsyncSync` and atomic rename.
   - Corrupted or invalid settings files automatically self-heal to canonical defaults on load without host crash.
