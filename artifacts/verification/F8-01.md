## Fail-Closed Security Invariants

The domain engine (`src/domain/sandbox.ts`) and backend service (`src/service/sandbox-image-service.ts`) reject execution under 11 mandatory failure conditions:

| Error Code | Trigger Condition | Behavior |
|---|---|---|
| `IMAGE_DIGEST_MISMATCH` | Actual container digest does not match pinned manifest digest | Execution terminated; error logged |
| `SANDBOX_IMAGE_MISSING` | Manifest file or offline store archive missing from project root | Fails closed before execution |
| `UNAPPROVED_PACKAGE_DETECTED` | Installed or referenced package outside frozen allowlist | Script execution rejected |
| `RUNTIME_INSTALL_FORBIDDEN` | Script or command attempts `pip`, `apt`, `conda`, `curl`, etc. | Operation blocked immediately |
| `MALFORMED_SANDBOX_MANIFEST` | Manifest JSON is corrupted, missing fields, or invalid schema | Fails closed during loading |
| `SANDBOX_MANIFEST_TAMPERED` | Manifest fields modified without valid cryptographic rehash | Fails closed on hash mismatch |
| `ROOT_EXECUTION_FORBIDDEN` | Container execution configured with UID 0 or `isRoot: true` | Container start blocked |
| `HOST_EXECUTOR_FORBIDDEN_IN_INDUSTRIAL` | Industrial profile attempts host `execute_python` | Bypassing sandbox blocked |
| `NETWORK_ACCESS_FORBIDDEN` | Script imports network sockets, HTTP clients (`socket`, `requests`, etc.) | Script blocked before container spawn |
| `INDEPENDENT_DIGEST_REQUIRED` | Image verification called without independently observed digest | Verification rejected fail-closed |
| `INVALID_DOCKER_ARCHIVE` | Archive is malformed, lacks `ustar` headers, missing manifest, digest mismatch, or lacks runtime files | Offline store rejected |
