## Executive Summary

Task **UI1-11** bridges the authoritative GPU residency and model leasing engine (`SharedModelManager`) from phases F4-04 / F5-03 into the core application services, REST API router, client SDKs, and browser GUI cockpit:

1. **Single Authoritative Model-Weight Owner**:
   - Reuses the existing `SharedModelManager` without spawning a duplicate residency system.
   - Strictly enforces that direct project-service weight loading is forbidden; all inferencing services request audited, project-scoped leases.

2. **Serialized GPU Residency & Concurrency Violations**:
   - Exactly one GPU model resident in VRAM at any time (`cuda` device).
   - Attempting to acquire or load a different GPU model while leases are active throws `CONCURRENCY_VIOLATION`.
   - VRAM overcommit exceeding manifest budget (`6144 MB` on target hardware) throws `OOM_BUDGET_EXCEEDED`.

3. **CPU Embedding Model Non-Eviction**:
   - CPU-bound embedding models (`sentence-transformers/all-MiniLM-L6-v2` / `all-MiniLM-L6-v2`, `vramRequiredMb: 0`, `device: 'cpu'`) acquire leases alongside the GPU model without evicting the resident GPU model weights from VRAM.

4. **Project- and Run-Scoped Leases & Boundary Enforcement**:
   - Leases are stamped with `projectId`, `runId`, `revision`, and `device`.
   - Cross-project lease release or renewal is strictly rejected (`CROSS_PROJECT_LEASE_ACCESS`).
   - Releasing a run-scoped lease with the wrong `runId` is rejected (`WRONG_RUN_LEASE_RELEASE`).
   - Active workflow runs protect the resident GPU model against switches (`WORKFLOW_FIXED_MODEL_PROTECTED`).

5. **Audited Lifecycle & Stale Lease Reaping**:
   - Leases feature explicit durations (`timeoutMs`), renewable via `renewLease` before expiration.
   - Expired lease renewal is rejected (`LEASE_EXPIRED`).
   - Stale leases are reaped via `pruneExpiredLeases` / `reapStaleLeases` / `recoverState`, recovering VRAM.
   - All lease acquisitions, renewals, releases, and reap operations are logged to the tamper-evident audit log.

6. **Air-Gap Invariants & Zero Runtime Downloads**:
   - Every registered model is verified against its offline snapshot manifest on disk (`assertSnapshotAvailable`).
   - Unregistered models are rejected (`MODEL_UNAVAILABLE`).
   - Revision mismatches are rejected (`REVISION_MISMATCH`).
   - Unhealthy model health probes reject lease acquisition (`MODEL_UNHEALTHY`).

7. **GUI Cockpit (`ModelsView.tsx`)**:
   - GPU Residency & VRAM Cockpit card displaying resident model ID, revision, device, active lease count, and VRAM utilization bar.
   - Pinned Model Manifest table displaying model identity, revision, parameter count, architecture, quantization, device, and required VRAM.
   - Active Model Leases table with individual Release buttons and project/run badge scopes.
   - Fair-priority queue architecture details panel explaining the 5 priority classes.

8. **4-Way Client Parity**:
   - Identical method signatures and typed validation across `ServiceContainer`, `RestApiRouter`, `MaosRestClient`, `BrowserRestClient`, and `GuiApiAdapter`.

## Architecture & Data Flow

```text
Operator / Agent in GUI
  │
  ├─ ModelsView.tsx
  │    ├─ [View Residency Cockpit] ──► GET /api/v1/models/residency
  │    │                                    │
  │    │                                    └─► SharedModelManager.getResidencyStatus()
  │    │
  │    ├─ [List Manifest & Leases] ─► GET /api/v1/models (registeredModels)
  │    │                             GET /api/v1/models/leases (?projectId=)
  │    │
  │    ├─ [Acquire Lease] ──────────► POST /api/v1/models/leases
  │    │                                    │
  │    │                                    ├─ Serialized GPU check (CONCURRENCY_VIOLATION)
  │    │                                    ├─ Workflow lock check (WORKFLOW_FIXED_MODEL_PROTECTED)
  │    │                                    ├─ Zero-download snapshot check (NO_RUNTIME_DOWNLOAD)
  │    │                                    ├─ Audit log event recorded
  │    │                                    └─ Returns ModelLease (project/run scoped)
  │    │
  │    ├─ [Renew Lease] ────────────► POST /api/v1/models/leases/:id/renew
  │    │                                    │
  │    │                                    ├─ Scope verification (CROSS_PROJECT_LEASE_ACCESS)
  │    │                                    └─ Rejects if expired (LEASE_EXPIRED)
  │    │
  │    ├─ [Release Lease] ──────────► DELETE /api/v1/models/leases/:id
  │    │                                    │
  │    │                                    ├─ Scope verification (CROSS_PROJECT_LEASE_ACCESS, WRONG_RUN_LEASE_RELEASE)
  │    │                                    └─ If 0 GPU leases, starts idle timer
  │    │
  │    └─ [Reap Stale Leases] ──────► POST /api/v1/models/leases/reap
  │                                         │
  │                                         └─ Prunes expired leases & recovers VRAM
```

## REST API Router Contracts

| Method | Endpoint | Description | Scope / Errors Enforced |
|:---|:---|:---|:---|
| `GET` | `/api/v1/models` | List models & registered manifest | Returns `data: models`, `registeredModels` |
| `GET` | `/api/v1/models/residency` | Authoritative residency status | Resident model, revision, device, VRAM used/budget, queue length |
| `GET` | `/api/v1/models/leases` | List active leases | Supports `?projectId=` filtering |
| `POST` | `/api/v1/models/leases` | Acquire audited lease | `CONCURRENCY_VIOLATION`, `OOM_BUDGET_EXCEEDED`, `WORKFLOW_FIXED_MODEL_PROTECTED`, `MODEL_UNAVAILABLE`, `MODEL_UNHEALTHY` |
| `POST` | `/api/v1/models/leases/:id/renew` | Extend lease expiry | `CROSS_PROJECT_LEASE_ACCESS`, `WRONG_RUN_LEASE_RELEASE`, `LEASE_EXPIRED` |
| `DELETE` | `/api/v1/models/leases/:id` | Release active lease | `CROSS_PROJECT_LEASE_ACCESS`, `WRONG_RUN_LEASE_RELEASE` |
| `POST` | `/api/v1/models/leases/reap` | Reap expired/stale leases | Returns `{ reapedCount }` |
| `DELETE` | `/api/v1/models/leases` | Release all active leases | Supports `?projectId=` filtering |
