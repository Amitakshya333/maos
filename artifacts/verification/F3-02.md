## Domain Architecture Summary

F3-02 establishes the canonical, versioned domain contracts for MAOS in `src/domain/`. Every entity shared across CLI, Web Dashboard, REST API, WebSocket streams, and future GUI/Tauri shells is defined here.

### Architectural Rules Enforced

1. **Explicit Schema Versioning**: Every schema possesses a `readonly schemaVersion: 1` field.
2. **Deterministic Enums**: String-literal unions are used exclusively (no ambiguous numeric TypeScript enums).
3. **Bounded Sizing**: Every string and collection property is governed by an exported constant limit (preventing memory exhaustion and unbounded inputs).
4. **Unknown Field Policy**: Unknown fields are permitted on read and safely stripped on write using `stripUnknownFields()`.
5. **Pure Validation**: `src/domain/validators.ts` depends on zero Node.js runtime APIs, allowing identical validation logic to be generated or shared across TypeScript, Rust, and Python.
