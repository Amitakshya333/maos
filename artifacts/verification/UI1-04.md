## Key Guarantees Enforced

### 1. Pre-Launch Project Folder Validation (`validator.ts`)
- **Fails Closed**: Complete validation runs *before* any child process or network listener is spawned.
- **Path Canonicalization & Normalization**: Path is canonicalized via `fs.realpathSync`.
- **Symlink / Junction Escape Rejection**: Symlinked project roots and path traversal escapes are rejected (`SYMLINK_PROJECT_ROOT_FORBIDDEN`).
- **Unsafe Temporary Location Check**: Projects located inside system temporary directories are rejected by default (`UNSAFE_TEMP_PROJECT_ROOT`) unless explicitly allowed via `allowTemp: true`.
- **Metadata Structure Check**: Verifies `.maos/` exists and is a directory (`MISSING_MAOS_DIRECTORY`, `MAOS_NOT_A_DIRECTORY`).
- **Configuration Parsing & Version Invariance**: Verifies `.maos/maos.config.json` exists, parses as valid JSON object, and declares `schemaVersion: 1` (`MISSING_PROJECT_CONFIG`, `INVALID_PROJECT_CONFIG`, `INCOMPATIBLE_SCHEMA_VERSION`).
- **Domain Schema Validation**: Integrates with domain validator `validateProject(config)` to verify `routingMode`, `providers`, `agents`, `routing`.
- **Deterministic Identity Hash**: Computes SHA-256 hash of canonical project root (`computeProjectRootHash`).

### 2. Child Process Host Spawning & Protocol (`entrypoint.ts`, `launcher.ts`)
- Spawns host service as an isolated child process via `child_process.spawn`.
- Line-delimited structured JSON readiness envelope over `stdout` and Node IPC channel (`stdio: ['pipe', 'pipe', 'pipe', 'ipc']`).
- **Zero Log Scraping**: Never parses unstructured log lines like `"Listening on port..."`. Emits strict `HostReadinessEnvelope` (`type: 'service_ready'`, `protocolVersion: '1.0'`).
- Handles startup timeout (default 10s) with clean tree-kill on hang (`STARTUP_TIMEOUT`).
- Detects premature exit with code/signal reporting (`HOST_EXITED_PREMATURELY`).

### 3. Independent Launcher Verification Protocol (`launcher.ts`)
The launcher does not blindly trust the child process self-report. It independently verifies:
1. **Envelope Structure**: Validates JSON schema, fields, and `protocolVersion === '1.0'` (`INVALID_READINESS_ENVELOPE`, `INCOMPATIBLE_PROTOCOL_VERSION`).
2. **PID Liveness & Ownership**: Checks `readiness.pid === child.pid` and verifies OS process liveness via `process.kill(child.pid, 0)` (`VERIFICATION_PID_MISMATCH`).
3. **Loopback Binding Verification**: Checks reported host is strictly loopback (`127.0.0.1`, `::1`, `localhost`) and port is within valid range (`VERIFICATION_HOST_NON_LOOPBACK`, `VERIFICATION_PORT_INVALID`).
4. **Project Root & Root Hash Check**: Confirms `readiness.projectRoot` matches canonical path and `readiness.projectRootHash` matches calculated SHA-256 (`VERIFICATION_ROOT_HASH_MISMATCH`, `VERIFICATION_ROOT_PATH_MISMATCH`).
5. **Independent TCP Loopback Probe**: Launcher creates a raw TCP socket connection to `(readiness.host, readiness.port)` to prove the port is actively accepting connections (`VERIFICATION_PORT_UNREACHABLE`).
6. **Durably Recorded Identity File Verification**: Reads `.maos/status/service-identity.json` and verifies that PID, port, instance ID, and project root hash match child and envelope (`VERIFICATION_IDENTITY_FILE_INVALID`).

### 4. Zero-Orphan Process Guarantee
- **Tree-Kill On Failure**: If any validation, spawn, envelope decode, or independent verification step fails, `killProcessTree(child.pid)` terminates the process and all its descendants.
  - Windows: `taskkill /T /F /PID <pid>`.
  - Unix: Process group / PID `SIGKILL`.
  - Polls until OS confirms process is dead (`isProcessAlive(pid) === false`).
- **Identity File Cleanup**: Deletes `.maos/status/service-identity.json` on stop or verification abort.
- **Global Process Exit Handler**: Registers single synchronized exit listener to kill all active child hosts if the launcher or test crashes or exits.
- **Crash Detection**: Detects child crashes post-readiness, marks host dead, and clears identity file.

### 5. Concurrency & Multi-Project Isolation
- **Duplicate Launch Prevention**: Attempting to launch an already-running project fails cleanly with `ALREADY_RUNNING` (or returns the existing instance if `reuseExisting: true`).
- **Stale Zombie Cleanup**: If `.maos/status/service-identity.json` exists with a dead PID, launcher purges stale state before spawning fresh.
- **Parallel Distinct Projects**: Distinct project folders launch concurrently on separate ephemeral ports with isolated tokens and state without interference.
