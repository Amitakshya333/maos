## Architecture (Revised)

### OwnedService — Identity-Verified Process Record

Every started service persists a full identity record:

```typescript
interface OwnedService {
  serviceId: string;     // e.g. 'rust-engine'
  pid: number;           // Verified via isProcessAlive()
  port: number;          // Bound port
  host: string;          // Loopback only
  executableHash: string; // SHA-256 of binary
  executablePath: string; // Absolute path
  projectRoot: string;   // Identity anchor
  protocolVersion: string;
  startedAt: string;
}
```

### Start Flow (Real F2-01 Integration)

```
lifecycleStart(configs) →
  for each config:
    spawnService(config)      → F2-01
    record OwnedService       (PID, hash, port, identity)
  partial failure?
    stopService(started[0..N-1]) → F2-01 process-tree kill
    state.phase = installed      (never running)
  all pass?
    state.phase = running
    persist ownedServices[]
```

### Stop Flow (Real F2-01 Integration)

```
lifecycleStop() →
  for each ownedService:
    stopService(svc.serviceId) → F2-01 process-tree kill
  state.phase = stopped
  state.ownedServices = []
```

### Reconciliation (Status/Health)

```
reconcileState() →
  for each ownedService:
    isProcessAlive(pid)?
      verify executable hash matches?
        → keep in live list
      hash mismatch?
        → stale (PID reused by different process)
    dead?
      → remove from owned list
  all dead?
    → auto-transition to 'stopped'
```

### Atomic Lock

```
acquireLock() →
  fs.writeFileSync(path, data, { flag: 'wx' })  ← atomic OS-level exclusive create
  EEXIST? → lock exists:
    read owner PID and timestamp
    age >= 30s AND isProcessAlive(ownerPid) === false?
      → remove stale lock, retry wx create
    else?
      → return false (lock held by live process)
```

### releaseLock() — Ownership Check

```
releaseLock() →
  read lock file → verify lockData.pid === process.pid
  match? → unlink
  mismatch? → do NOT remove (another process owns it)
```
