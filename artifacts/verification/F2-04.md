## Architecture

Six offline dependency stores, each with validation + build instructions:

```
offline-stores/
├── npm/              # npm pack tarball
├── python-wheels/    # pip download wheelhouse
├── tesseract/        # OCR binary/installer
├── sandbox-image/    # docker save tarball
└── model-snapshot/   # HuggingFace model snapshot
rust/vendor/          # cargo vendor output
```

Every store:
- Has a **validation function** (runs on air-gapped target)
- Has **build commands** (runs on networked machine)
- Returns **actionable error messages** on failure
- **Never** silently fetches from the network

## Store Summary

| # | Store | Validation | Build Command |
|---|---|---|---|
