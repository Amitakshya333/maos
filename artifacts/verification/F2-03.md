## What Was Built

### Bundle Manifest Generator (`src/industrial/bundle-manifest.ts`)

Generates a deterministic, verifiable manifest of all files needed for offline deployment.

| Feature | Implementation |
|---|---|
| **Deterministic output** | Sorted paths (case-insensitive, forward-slash normalized), stable JSON |
| **SHA-256 per file** | Every entry includes size + hash for tamper detection |
| **11 categories** | rust-binary, ts-dist, config, schema, script, template, model-snapshot, python, container, asset, react-asset |
| **Build identity** | Platform, arch, Node/Rust/Python versions, timestamp, entries hash |
| **Model snapshot** | Detects and hashes `model-snapshot-manifest.json` if present |
| **Exclusions** | node_modules, .git, .env, secrets, debug builds, __pycache__, dist (unless opted in) |
| **Verification** | `verifyBundleManifest()` detects missing, tampered, size-mismatch, unlisted executables |
| **I/O** | `writeManifest()` / `readManifest()` with roundtrip fidelity |

### Category Detection Rules

| Category | Detection |
|---|---|
| `rust-binary` | Under `rust/target/release/`, .exe/.dll/no-ext |
| `ts-dist` | Under `dist/` |
| `config` | package.json, tsconfig.json, Cargo.toml, profiles/, requirements.lock |
| `schema` | `.schema.json` or filename contains "schema" |
| `script` | Under `scripts/`, .sh/.ps1/.bat/.cmd |
| `template` | Under `templates/`, .hbs/.mustache/.ejs |
| `model-snapshot` | Filename contains "model-snapshot"/"model-manifest", under `models/` |
| `python` | .py files, requirements.txt/lock |
| `container` | Dockerfile, docker-compose.* |
| `react-asset` | Under `gui/build/` or `gui/dist/` |
| `asset` | Images, CSS, fonts |

### Exclusion Rules

| Excluded | Reason |
|---|---|
| `node_modules/` | Rebuilt from lockfile |
| `.git/` | Not deployable |
| `.env`, `.env.*` | Secrets |
| `target/debug/` | Debug builds not permitted |
| `__pycache__/` | Generated cache |
| `dist/` | Default off, opt-in via `includeDist` |
| `*.pem`, `*.key`, `*secret*` | Credential patterns |
