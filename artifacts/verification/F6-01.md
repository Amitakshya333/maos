## Executive Summary

Task **F6-01** establishes the foundational domain contract, type definitions, security invariants, pure validators, deterministic canonical hashing, and freshness verification service for generating real, editable office deliverables (DOCX approval notes, XLSX calculation/evidence workbooks, and PPTX executive briefing decks).

## Core Implementations

### 1. Versioned Typed Domain Schemas (`src/domain/office-artifact.ts`)
- **Output Types Supported**: `'docx' | 'xlsx' | 'pptx'` via `OfficeArtifactType`.
- **Common Validated Contract**: `ValidatedOfficeArtifactInput` defining:
  - `schemaVersion: 1`
  - `projectId: string` (strictly confined to active project root)
  - `runId: string` and optional `taskId: string`
  - `artifactType: OfficeArtifactType`
  - `title: string` (bounded: 3 to 256 characters)
  - `author: OfficeAuthorIdentity` (`id`, `name`, optional `role`)
  - `sections: readonly OfficeReportSection[]` (order, headings, content, tabular data, unverified prose)
  - `findings: readonly OfficeFinding[]` (statement, severity, PASS/WARNING/FAIL status, metric, observed/threshold values, mandatory unit and citations)
  - `measurements: readonly OfficeMeasurement[]` (numericValue, mandatory unit, tolerance, nominal/out_of_spec status, mandatory citations)
  - `units: readonly string[]` (verified set of engineering units referenced)
  - `calculations: readonly OfficeCalculation[]` (inputs, formula, resultValue, resultUnit, verifiedBy method)
  - `warnings: readonly OfficeWarning[]` (code, message, severity, acknowledgement)
  - `limitations: readonly string[]` (system/model bounds)
  - `citations: readonly OfficeCitation[]` (exact `sourcePath`, `sourceHash`, `snippet`, page, section, chunk ID)
  - `sourceArtifactIds: readonly string[]` and `sourceHashes: Record<string, string>`
  - `references: readonly OfficeSourceReference[]`
  - `evidenceState: OfficeEvidenceState` (OCR/VLM confidence scores, conflict review classification, quarantine status, human review record)
  - `modelIdentity: { modelId: string; revision: string }`
  - `generatedAt: string` (ISO timestamp)
  - `approval: OfficeApproval` (required, status, approvalId, approvedBy, approvedAt, payloadHash)
  - `proseBlocks: readonly OfficeProseBlock[]` (unverified model prose distinctly segregated)
  - `conclusions: readonly OfficeConclusion[]` (binding human verdict and sign-off)
- **Specialized Types**: `OfficeDocxInput`, `OfficeXlsxInput`, and `OfficePptxInput` extending the base contract with format-specific configuration options.

### 2. Strict Separation of Concerns
The contract enforces explicit boundaries between:
1. **Validated Structured Data**: Immutable facts, measurements with mandatory units, verified calculations.
2. **Citations & Provenance**: Cryptographic source hashes and exact page/chunk references.
3. **Unverified Model Prose**: Segregated in `proseBlocks` or `unverifiedModelProse`, tagged `isModelGenerated: true` and `verifiedAgainstData: false`, treated as untrusted until reviewed.
4. **Reviewer Corrections**: `reviewerCorrection` tracking `reviewerId`, `originalValue`, `correctedValue`, and `reason`.
5. **Conclusions**: Binding human decision and sign-off.

### 3. Fail-Closed Security & Confinement Rules
- **Spreadsheet Security (`isPotentialFormulaInjection`)**:
  - Rejects strings beginning with `=`, `@`, `\t`, `\r`, or `+`/`-` followed by non-numeric characters.
  - Rejects dangerous formula calls (`DDE`, `HYPERLINK`, `WEBSERVICE`, `IMPORTXML`, `cmd`, `exec`).
  - Preserves valid signed numeric literals (e.g. `-12.5`, `+5`).
- **Document & Presentation Security**:
  - Rejects macro indicators (`.docm`, `.xlsm`, `.pptm`, `vbaProject`, `wscript.shell`, `powershell.exe`).
  - Rejects script execution tags (`<script>`, `javascript:`).
  - Rejects external relationships (`containsExternalRelationship`: `http://`, `https://`, `ftp://`, `file://`).
- **Path Confinement (`isSafeIndustrialPath`)**:
  - Rejects directory traversal (`..`).
  - Rejects absolute Windows/Unix paths (`C:\...`, `/etc/...`).
  - Rejects null bytes (`\0`).
  - Rejects URI schemes (`file:`, `http:`).
- **Evidence & Approval Guardrails**:
  - Rejects unresolved conflicts (`hasUnresolvedConflicts: true` or `REQUIRES_HUMAN_REVIEW` with `unresolved`).
  - Rejects quarantined evidence (`isQuarantined: true`).
  - Rejects low OCR confidence (< 0.70) or VLM confidence (< 0.60) unless explicitly reviewed by a human (`reviewedByHuman: true`).
  - Rejects unapproved inputs when approval is required (`approval.required: true` and `status !== 'approved'`).
  - Rejects cross-project submissions (`input.projectId !== activeProjectId`).

### 4. Deterministic Canonical Hashing & Stale-Input Detection
- **`computeOfficeInputHash`**: Canonicalizes input with recursively sorted keys, independent of object key ordering; produces authoritative SHA-256 digest.
- **`OfficeInputService.verifyFreshness`**:
  - Verifies each source file on disk matches its citation `sourceHash`.
  - Verifies referenced `sourceArtifactIds` in `ArtifactService`.
  - Verifies required approvals in `ApprovalService`.
  - Detects modifications to disk files or revoked approvals and flags input as stale.
- **Audit Integration**: Records `OFFICE_INPUT_VALIDATED`, `OFFICE_INPUT_REJECTED`, `OFFICE_INPUT_FRESHNESS_VERIFIED`, and `OFFICE_INPUT_STALE_DETECTED` with cryptographic input hashes and zero raw text or secrets.
