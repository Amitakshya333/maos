## 3. Verified Security Dimensions

### 1. Token Isolation & Swap Rejection
- **Instance Binding:** Session tokens generated by `SessionManager` embed the cryptographic hash of the project root and the ephemeral `serviceInstanceId`.
- **Token Swap Attack:** When a valid session token from `Host A` is presented in an `Authorization: Bearer <tokenA>` header to `Host B`, `Host B` immediately detects the foreign project root hash / instance identity and rejects the request with HTTP 401 (`INVALID_TOKEN` / `SESSION_NOT_FOUND`).
- **URL Parameter Leakage Defense:** Requests attempting to pass session credentials via query parameters (`?token=...`, `?bearer=...`, etc.) are unconditionally rejected with HTTP 400 (`FORBIDDEN_URL_TOKEN`) before routing or logging, preventing token leakage into web server logs.

### 2. Header & Project Scope Enforcement
- **`X-Project-Root` Defense:** Incoming requests presenting an `X-Project-Root` header that differs from the server's canonical project root are rejected with HTTP 400 `PROJECT_SCOPE_MISMATCH`.
- **`X-Project-ID` Defense:** Incoming requests with an `X-Project-ID` header mismatching the loaded project's name are rejected with HTTP 400 `PROJECT_SCOPE_MISMATCH`.

### 3. Artifact Store & Confinement Isolation
- **Artifact Confinement:** Artifacts finalized in `Project Alpha` cannot be located, queried, or downloaded from `Project Beta` (`404 NOT_FOUND`).
- **Path Traversal Escape Prevention:** Relative path traversal attempts (e.g., `../../project-alpha/artifacts/escaped.docx`) targeting foreign directories are rejected with HTTP 400 `PATH_TRAVERSAL` / `PATH_OUTSIDE_PROJECT`.

### 4. Conversation & Task Isolation
- **Conversation Confinement:** Conversations created within `Project Alpha` are inaccessible to `Project Beta` (`404 NOT_FOUND`).
- **Cross-Project Injection Prevention:** Attempts by `Project Beta` to append messages to a `Project Alpha` conversation ID fail closed with `404 NOT_FOUND`.

### 5. Settings Isolation
- **Per-Project Isolation:** Mutating configuration settings in `Project Alpha` (e.g. `routingMode: 'cheapest_first'`) takes effect in `Project Alpha` immediately while leaving `Project Beta` in its default state (`routingMode: 'auto'`).
- **Query Scoping:** Cross-project settings queries with foreign project identifiers are either rejected with `CROSS_PROJECT_FORBIDDEN` or strictly scoped to the active project's own settings.

### 6. Cockpit Run & Event Replay Isolation
- **Runtime-Derived DAGs:** Cockpit runs reconstruct state and stage indicators deterministically from the project's own `WorkflowPlan` and sequenced event stream.
- **Run Privacy:** Cross-project requests attempting to query a run or replay event streams belonging to another project return HTTP 404 `NOT_FOUND`.

### 7. Recent Projects Registry & Canonicalization
- **Canonical Paths:** The `RecentProjectStore` canonicalizes directory paths, derives unique `projectRootHash` identifiers, and stores non-sensitive metadata in global app data outside individual project trees.
- **Zero Secrets on Disk:** Zero tokens, passwords, or session keys are ever written to the recent projects catalog.
