## Executive Summary

Task **F4-05** exposes the pinned local Vision-Language Model (`Qwen/Qwen2-VL-2B-Instruct`, revision `aa70c964147048705c93c4e16ff2bc55255470d0`) through the approved MAOS tool boundary via `analyze_image`.

### Core Industrial Principles Enforced

1. **Tool Flow Integration & Advertisement Filtering**:
   - `Agent request` → `Tool advertisement filter (getToolsForAgent)` → `Execution authorization` → `Project path / image validation` → `Image bounds validation` → `Shared Model Manager lease` → `Pinned VLM inference` → `Typed observation result` → `Artifact finalization` → `Audit event` → `Guaranteed lease release in finally`.
   - `getToolsForAgent` advertises `analyze_image` only to authorized agents (`ingest_agent`, `analyst_agent`, `auditor_agent`, `inspector`, `admin`).
   - Profile `profiles/industrial/maos.config.json` grants `analyze_image` to `INGEST_AGENT` and `ANALYST_AGENT`.

2. **Versioned Input Schema & Bounds (`AnalyzeImageInput`)**:
   - Schema version 1 with strict mutual exclusivity: exactly one of `sourcePath` XOR `sourceArtifactId`.
   - Project-root confinement: path traversal (`../`), null bytes, and symlink escapes outside the project root are rejected with `TRAVERSAL_REJECTED`.
   - File formats and headers: supports `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`. Validates header magic bytes; rejects corrupted/fake extensions with `UNSUPPORTED_IMAGE_FORMAT`.
   - Resource limits: file size <= 20 MB (`VISION_BOUNDS.maxSourceBytes`), dimensions <= 14400 px, total pixels <= 100 MP (`VISION_BOUNDS.maxImagePixels`), prompt length <= 4096 characters, tokens <= 2048 (`VISION_BOUNDS.maxOutputTokens`).

3. **Shared Model Manager Lease Protocol (Section 4.2 Invariant)**:
   - Weights are never loaded directly by project services.
   - Audited leases are acquired via `SharedModelManager.acquireLease` / `acquireLeaseSync` (`priority: 'user_task'`).
   - Lease release is **strictly guaranteed in the `finally` path** across all execution paths (success, model inference failure, schema error, timeout, or cancellation).

4. **Structured Visual Observations & Critical Safety Invariant**:
   - Visual observations are returned as typed `ImageObservation[]` across 4 industrial task types:
     - `measurement`: extracts visual dimension estimates with bounding boxes; **always sets `requiresReview: true`** (uncalibrated estimate).
     - `label-reading`: visual text readings with confidence and bounding boxes.
     - `drawing-observation`: visual notes, symbols, and geometric layout observations; sets `requiresReview: true`.
     - `general-observation`: general scene descriptions and equipment condition.
   - **CRITICAL INVARIANT**: Observations are **NEVER** converted directly into compliance/safety verdicts. OCR facts and VLM observations remain strictly segregated until multi-modal conflict review (F4-06).

5. **Safe Artifact Store & Append-Only Audit Trail**:
   - Output artifact atomically finalized at `evidence/vision/<sourceHash[:16]>/observations.json`.
   - Immutable audit event (`IMAGE_ANALYZED`) recorded in `.maos/audit/audit-chain.jsonl` **strictly after** artifact finalization.
   - Zero phantom audit events or partial artifacts on validation, confinement, or inference failure.

6. **Durable Mutation Idempotency**:
   - Integrated with `DurableIdempotencyStore`. Exact replays return cached results (`cached: true`).
   - Conflicting payloads on identical `requestId` fail with `IDEMPOTENCY_CONFLICT`.
   - Authorization context mismatches fail with `UNAUTHORIZED_TOOL_CALL`.
