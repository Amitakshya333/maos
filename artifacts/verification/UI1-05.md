## Executive Summary

Task **UI1-05** has been implemented, validated, and fully verified. It provides the MAOS Launcher with a robust, global, versioned metadata store for recent projects outside project directories, enabling users to:
1. View recently opened projects deterministically sorted by last-opened timestamp.
2. Reopen available projects with comprehensive revalidation before launch.
3. Track availability status (`available`, `unavailable`, `relocation_required`) without deleting records when folders move or go offline.
4. Explicitly relocate moved projects, retaining stable project identity and requiring explicit confirmation (`RelocationConfirmationRequiredError`) if the target folder represents a different project.
5. Maintain strict token and secret hygiene: zero session tokens, credentials, audit payloads, or model secrets are written to disk.
6. Recover safely from corrupt metadata without crashing or inventing projects.

## Key Guarantees Enforced

### 1. Global Metadata Store (`recent-projects.ts`)
- **Location**: Platform-appropriate global application data path:
  - Windows: `%APPDATA%/maos/recent-projects.json`
  - macOS: `~/Library/Application Support/maos/recent-projects.json`
  - Linux: `$XDG_DATA_HOME/maos/recent-projects.json` or `~/.local/share/maos/recent-projects.json`
  - Overridable via `MAOS_RECENT_PROJECTS_PATH` env var or constructor `storagePath`.
- **Model**:
  ```ts
  interface RecentProject {
    projectId: string;
    displayName: string;
    canonicalPath: string;
    projectRootHash: string;
    lastOpenedAt: string;
    lastKnownAt: string;
    status: 'available' | 'unavailable' | 'relocation_required';
    schemaVersion: 1;
  }
  ```
- **Strict Hygiene**: Metadata strictly contains only the 8 non-sensitive fields listed above. Zero tokens, passwords, API keys, or chat content.
- **Deterministic Ordering**: Projects are deterministically sorted by `lastOpenedAt` descending (newest first), with `projectId` tie-breaker.
- **Duplicate Consolidation**: Recording an existing project updates its timestamps and path in-place rather than creating duplicate entries.
- **Bounded History**: Enforces `maxEntries` (default 50); oldest entries beyond the limit are pruned.

### 2. Available-Project & Revalidation Protocol (`launcher.ts`)
- `launcher.launch(folderPath)` automatically records or updates the project in `recentStore`.
- `launcher.launchRecent(projectId)`:
  1. Retrieves recent project record.
  2. Revalidates status against the filesystem using UI1-04 validator.
  3. If missing: fails closed with `PROJECT_UNAVAILABLE`. Record is preserved in history.
  4. If identity changed: fails closed with `RELOCATION_REQUIRED`.
  5. If available: launches host through the UI1-04 verification protocol.

### 3. Explicit Relocation Protocol
- Relocation requires explicit user action.
- Target folder is validated via `assertValidProjectFolder`:
  - Must exist and be a directory.
  - Must contain `.maos/` and valid `maos.config.json`.
  - Rejects symlink/junction targets unless `allowSymlinks: true`.
  - Rejects path traversal.
- **Stable Identity Preservation**:
  - Stable project identity is tracked via `.maos/project-id` or `config.profile?.id`.
  - When moving a folder, `.maos/project-id` is preserved, allowing seamless relocation to the same project.
  - If target folder has a different `projectId`, relocation throws `RelocationConfirmationRequiredError` unless `confirmDifferentIdentity: true` is explicitly passed.
  - Never silently substitutes a different project.

### 4. Storage Reliability & Concurrency
- **Atomic Writes**: Uses `.recent-projects.<timestamp>.<hex>.tmp`, flushes to disk with `fs.fsyncSync`, and performs atomic `fs.renameSync`.
- **Concurrency Safety**: File-level locking (`storagePath + '.lock'`) with retry backoff and stale-lock recovery prevents race conditions during concurrent updates.
- **Corrupt Metadata Recovery**: If metadata contains invalid JSON, invalid root type, or unsupported `schemaVersion`, store recovers safely to an empty project list with a diagnostic message without crashing.
