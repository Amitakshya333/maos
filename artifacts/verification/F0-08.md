## D7 GUI Judged Journey Storyboard

### Acceptance Criterion

> A new user opens MAOS Industrial GUI and, within 15 minutes, can submit a scanned inspection report, watch agents analyze it through the DAG, review OCR findings with confidence scores, approve the safety verdict, and download a DOCX approval note with citations using a local model while seeing the complete audit trail, active model identity, and sovereign evidence that no non-loopback application traffic was observed within the defined monitored boundary.

### Step-by-Step Storyboard

| Step | User Action | GUI Response | Time Budget |
|---|---|---|---|
| 1 | Launch MAOS Industrial | Launcher opens; project list shown | < 5s |
| 2 | Select/create project folder | `.maos/` created if needed; project service starts on ephemeral port; role preset asked | < 5s |
| 3 | Choose Inspector/Analyst preset | Layout pins evidence workbench and cockpit prominently | < 1s |
| 4 | Click "Upload Evidence" | File picker opens (no drag-and-drop in MVP) | < 1s |
| 5 | Select scanned inspection PDF | File validated, ingested, OCR starts; task appears in feed | < 3s |
| 6 | Watch agent cockpit | DAG shows: INGEST → ANALYZE → AUDIT → SYNTHESIZE → GENERATE → VERIFY; stages progress with live model/tool/status indicators | Duration of inference |
| 7 | Review OCR findings | Evidence workbench shows original page, extracted text, confidence scores | < 2s after OCR |
| 8 | Review threshold results | Findings panel shows each measurement vs. threshold, verdict, citation | < 1s after Rust eval |
| 9 | Approve safety verdict | Approval dialog: verdict, scope, findings summary; user confirms | User time |
| 10 | Download DOCX | Document generator shows preview; user clicks download; file opens in MS Office | < 5s |
| 11 | Check audit trail | Audit panel shows all events: source hashes, model IDs, tool calls, approvals, timestamps | < 1s |
| 12 | Check sovereign panel | Shows: local endpoints, active model/revision, firewall state, observed connections, process tree, model leases | < 1s |

**Total automated time (excluding user reading/approval): < 10 minutes with GPU inference.**

### Four Role Presets

| Preset | Primary Panels | Secondary Panels |
|---|---|---|
| Developer | Chat, Sandbox Results, Task Feed | Cockpit, Settings |
| Inspector/Analyst | Evidence Workbench, Cockpit, Audit | Chat, Task Feed, KB Search |
| Architect | Cockpit, Audit, Settings, Model Switcher | Chat, Evidence, KB |
| Manager/Reviewer | Task Feed, Documents, Audit, Sovereign | Chat, Evidence |

All presets access the same modules and engine. Presets change only the default pinned layout.

### One-Shell Decision

✅ **Confirmed: one adaptive VS Code-like shell.** Not four separate applications.
- Navigation sidebar with module icons
- Resizable panels/regions
- Role preset changes pinned layout only
- All modules accessible from any preset

### One-Project MVP

✅ **Confirmed: judged GUI opens one project.**
- Launcher shows project list but MVP opens exactly one service
- No multi-project tabs or window management in MVP UI
- Architecture (project-scoped service, per-project tokens, isolated APIs) supports v1.1 parallel windows without API changes

## Accessibility Baseline Target

| Area | MVP Target |
|---|---|
| Keyboard navigation | All interactive elements reachable via Tab/Enter/Escape |
| Focus indicators | Visible focus ring on all interactive elements |
| Labels | All form controls have associated labels |
| Contrast | WCAG 2.1 AA minimum (4.5:1 for text) |
| Reduced motion | Respect `prefers-reduced-motion` |
| Screen reader | Basic landmark roles (`main`, `nav`, `aside`) and live regions for task updates |
| Error states | Text descriptions, not color-only |
| Reconnect/offline | Visible banner with recovery action, not silent failure |

This is a **baseline target**, not a certified accessibility audit. Full WCAG audit is post-MVP.

## Monitored Boundary Wording

The sovereign panel displays:
- "Monitored boundary: MAOS application processes and configured endpoints"
- "Observation period: [start timestamp] – [current/end timestamp]"  
- "Non-loopback connections observed: [count]"
- "Blocked connection attempts: [count]"

Never: "Zero data left the machine" or "Tamper-proof" or "Complete network isolation verified."
