## Architecture

Six distinct, sequentially gated preflight stages:

```
static → deps → services → health → smoke → cleanup
         ↑                    ↑
         │ blocks startup     │ failure triggers cleanup
```

- **Static failure** prevents dependency and service stages.
- **Dependency failure** prevents service startup.
- **Health failure** stops services started by this run.
- Pre-existing services reused ONLY after identity + hash + port + protocol checks pass.

## Stage Summary

| # | Stage | Exit Code Range | Checks |
|---|---|---|---|
| 1 | `static` | 30-35 | Manifest exists, file exists, size, SHA-256, release binary, protocol/version metadata, model snapshot, configs |
| 2 | `deps` | 40-46 | Node version, Python version, Python packages, Rust engine health/version, Docker/Podman, Tesseract OCR |
| 3 | `services` | 50-52 | Rust engine start, model server port claim, loopback enforcement, identity verification, ownership tracking |
| 4 | `health` | 60-65 | Rust engine health+protocol, model server, OCR, embedding, vision, sandbox image |
| 5 | `smoke` | 70-72 | Fixed request, structured response, protocol+engine identity, latency+output hash, explicit disclaimer |
| 6 | `cleanup` | 80 | Stop owned services only, process tree termination, temp removal, evidence preservation |
