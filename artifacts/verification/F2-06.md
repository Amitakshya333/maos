## Architecture

Every service declares a pinned `ServiceIdentityManifest` at build time. Runtime health probes compare live service data against the manifest. **Mismatch or absent identity = UNHEALTHY.**

```
Build time: create manifest → register → write to disk
Runtime:    probe live service → compare to manifest → healthy/unhealthy
```

## Health Status Values

| Status | Meaning |
|---|---|
| `healthy` | All registered services match their manifests |
| `unhealthy` | One or more services mismatched or absent |
| `degraded` | Reserved for partial functionality |
| `unknown` | No manifests registered |
