## Executive Summary

Task **UI1-17** delivers the **Air-Gapped Document Generator**, an industrial-grade deliverable production system providing template validation, live input inspection, cryptographic freshness verification, mandatory human approval gating, deterministic OOXML package compilation (DOCX, XLSX, PPTX), and external launcher integration.

The Document Generator is directly bound to sovereign backend services (`DocxGeneratorService`, `XlsxGeneratorService`, `PptxGeneratorService`, `OfficeInputService`, `OfficeTemplateSafetyService`, `ArtifactService`, and `ApprovalService`), enforcing strict zero-trust rules:
1. **Deterministic Canonical Hashing**: All inputs are normalized via recursive key sorting (`canonicalizeJson`) and cryptographically bound via SHA-256 before generation.
2. **Mandatory Approval Gating**: Document generation strictly requires an authorized human approval record (`ApprovalService`) bound to the exact payload hash. Unapproved requests, pending requests, or tampered inputs are rejected with HTTP 403 (`APPROVAL_REQUIRED` / `CHANGED_INPUT_AFTER_APPROVAL`).
3. **Cryptographic Freshness & Provenance**: Citations are verified against physical files on disk. Stale source hashes or missing files reject generation immediately with `STALE_SOURCE_HASH`.
4. **Template Safety & Sanitization**: Templates are inspected against path traversal, macro extensions (`.docm`, `.xlsm`, `.pptm`), remote relationship targets (`targetMode="External"`), and spreadsheet formula injection (`=cmd|...`).
5. **Safe Artifact Finalization**: Deliverables are finalized atomically into the Safe Artifact Store with authoritative Rust SHA-256 hashing. Silent overwrite is forbidden unless `allowOverwrite: true` is granted.
6. **Safe Native External Launcher**: Opens generated deliverables in the host OS viewer (`explorer.exe` on Windows, `open` on macOS, `xdg-open` on Linux) with shell injection prevention and path traversal rejection.

  - `demo/industrial/maintenance_report.txt` (`7ed8e5b9f2a9fb74e212f70c2e78768b1850d7815d7c633a8af381f61bb08503`)

### 2. Backend REST Endpoints (`src/api/router.ts`)
- `GET /api/v1/generator/presets`: Returns available deliverable presets with real fixture SHA-256 hashes.
- `POST /api/v1/generator/validate-input`: Evaluates schema validity, computes canonical hash, and verifies citation freshness against disk sources.
- `POST /api/v1/generator/validate-template`: Inspects OOXML template packages for path traversal, macros, and external relationships.
- `POST /api/v1/generator/generate`: Dispatches to `docxGenerator`, `xlsxGenerator`, and `pptxGenerator`, enforcing approval payload hash match and saving to the Safe Artifact Store.
- `POST /api/v1/generator/launch`: Launches deliverables in the native OS viewer safely without shell interpolation.
- `GET /api/v1/generator/artifacts`: Queries finalized office deliverables from `ArtifactService`.

### 3. Client & Adapter Layer (`src/gui/src/api/rest-client.ts`, `src/gui/src/api/adapter.ts`)
- Typed client contracts: `GeneratorPreset`, `GeneratorValidationResponse`, `TemplateValidationResponse`, `GenerateDocumentPayload`, `GenerateDocumentResponse`, `LaunchDocumentResponse`.
